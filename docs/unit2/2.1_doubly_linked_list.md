# Unit 2: Doubly Linked List

---

## 13.1 Concept

**Doubly Linked List:** Each node has **two pointers** — `next` (forward) and `prev` (backward).

```
[HEAD] ←→ [10] ←→ [20] ←→ [30] ←→ [TAIL]
```

### Structure:
```c
struct node {
    int key_;
    struct node *prev_;
    struct node *next_;
};
typedef struct node node_t;

struct DLL {
    node_t *head_;  // First node
    node_t *tail_;  // Last node
};
typedef struct DLL dll_t;
```

---

## 13.2 Operations

### Init:
```c
void init_dll(dll_t* l) { l->head_ = l->tail_ = NULL; }
```

---

## 13.3 Insertion (4 Cases)

### Middle (before `pres`):
```c
temp->next_ = pres;
temp->prev_ = pres->prev_;
pres->prev_->next_ = temp;
pres->prev_ = temp;
```
**4 pointer changes!**

### Four Boundary Cases:
| Case | Action |
|------|--------|
| **Empty list** | `head = tail = temp; temp->prev = temp->next = NULL` |
| **Beginning** | `temp->next = head; head->prev = temp; head = temp` |
| **End** | `temp->prev = tail; tail->next = temp; tail = temp` |
| **Middle** | 4 pointer updates (as above) |

---

## 13.4 Deletion (4 Cases)

### Middle (`temp` is node to delete):
```c
temp->next_->prev_ = temp->prev_;
temp->prev_->next_ = temp->next_;
free(temp);
```

### Four Boundary Cases:
| Case | Action |
|------|--------|
| **Only node** | `head = tail = NULL; free(temp)` |
| **First node** | `head = temp->next; head->prev = NULL; free(temp)` |
| **Last node** | `tail = temp->prev; tail->next = NULL; free(temp)` |
| **Middle** | `temp->prev->next = temp->next; temp->next->prev = temp->prev; free(temp)` |

---

## 13.5 Traversal

```c
// Forward
for (node_t* p = l->head_; p; p = p->next_) { ... }

// Backward
for (node_t* p = l->tail_; p; p = p->prev_) { ... }
```

---

## 13.6 Deinit

```c
void free_dll(dll_t* l) {
    node_t* p = l->head_;
    while (p) {
        node_t* next = p->next_;
        free(p);
        p = next;
    }
    l->head_ = l->tail_ = NULL;
}
```

---

## 13.3 Comparison: Singly vs Doubly

| Operation | Singly | Doubly | Winner |
|-----------|--------|--------|--------|
| Move forward | 1 step | 1 step | Tie |
| Move backward | O(n) | 1 step | **Doubly** |
| Insert before node | O(n) find prev | O(1) given node | **Doubly** |
| Delete given node | O(n) find prev | O(1) | **Doubly** |
| Search | O(n) | O(n) | Tie |
| Space | 1 ptr/node | 2 ptrs/node | **Singly** |

**Key Insight:** Doubly linked list = **Time-Space Tradeoff**
- More space (extra pointer)
- Faster local operations (insert/delete given node)

---

## 13.4 Applications

| Application | Why Doubly? |
|-------------|-------------|
| **Browser History** | Back/Forward navigation |
| **Music Playlist** | Prev/Next track |
| **Undo/Redo** | Backward/forward |
| **LRU Cache** | Move to front, evict from back |
| **Round Robin** | Circular + bidirectional |

---

## Summary

| Aspect | Detail |
|--------|--------|
| **Node** | `key, prev, next` |
| **List** | `head, tail` |
| **Insert middle** | 4 pointer updates |
| **Delete middle** | 2 pointer updates + free |
| **Traversal** | Forward & backward |
| **Space** | 2 pointers/node |
| **Search** | Still O(n) |

## MCQ Practice

**Q1:** Insert before node in singly vs doubly?
**A:** Singly: O(n) to find prev | Doubly: O(1) via `prev`

**Q2:** Delete given node in singly vs doubly?
**A:** Singly: O(n) to find prev | Doubly: O(1) via `prev`

**Q3:** Does doubly linked list make search faster?
**A:** NO — both O(n)

**Q4:** How many pointers updated in DLL middle insert?
**A:** 4

**Q4:** DLL middle delete?
**A:** 2 pointer updates + free

**Q5:** What does `prev` of head point to?
**A:** NULL

**Q6:** What does `next` of tail point to?
**A:** NULL
