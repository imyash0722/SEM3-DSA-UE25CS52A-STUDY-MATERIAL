# Unit 2: Priority Queue

---

## 16.1 Concept

**Priority Queue:** ADT where each element has a **priority**
- **Ordinary Queue:** FIFO (arrival order)
- **Priority Queue:** Highest priority removed first

### Priority Convention:
- Higher number = Higher priority (our examples)
- *Unix opposite: lower number = higher priority (`nice` command)*

### Example:
```
Jobs:    #103(pri=10)  #102(pri=50)  #104(pri=30)
Queue:   103 → 102 → 104  (arrival)
Dequeue: 102 (pri=50) first!  (highest priority)
```

---

## 16.2 Interface

```c
struct job { int job_no_; int priority_; };
typedef struct job job_t;

void init_pq(pq_t* q);
void deinit_pq(pq_t* q);
void enque(pq_t* q, job_t* job);
job_t deque(pq_t* q);       // Returns highest priority
int is_empty(pq_t* q);
int is_full(pq_t* q);
```

## 16.4 Five Implementations

| # | Implementation | Insert | Delete Max |
|---|---------------|--------|------------|
| 1 | **Unordered List** | O(1) | O(n) - scan |
| 2 | **Ordered List** | O(n) | O(1) - at front/end |
| 3 | **Unordered Array** | O(1) | O(n) - scan |
| 4 | **Ordered Array** | O(n) | O(1) |
| 5 | **Heap** | O(log n) | **O(log n)** |

### Comparison Table:
| Implementation | Insert | Delete Max |
|----------------|--------|------------|
| Unordered List | O(1) | O(n) |
| Ordered List | O(n) | O(1) |
| Unordered Array | O(1) | O(n) |
| Ordered Array | O(n) | O(1) |
| **Heap** | **O(log n)** | **O(log n)** |

**Heap wins:** Balanced O(log n) for both!

## 16.7 Client Code (Unchanged Across Implementations)

```c
pqueue_t q; init_pq(&q);
job_t job; int priority, job_no = 1;

while (1) {
    printf("1:enque 2:deque 0:quit\n");
    scanf("%d", &opt);
    
    if (opt == 1) {
        scanf("%d", &priority);
        set_job(&job, job_no++, priority);
        enque(&q, &job);
    } else if (opt == 2) {
        job = deque(&q);
        disp_job(&job);
    }
}
```

## MCQ Practice

**Q1:** Priority queue vs ordinary queue?
**A:** PQ removes by priority; Queue removes by arrival order (FIFO)

**Q2:** Higher priority number = ?
**A:** Higher priority (in our convention)

**Q3:** Unordered list: insert O(1), delete O(n)?
**A:** Insert at head; scan for max on delete

**Q3:** Ordered list: insert O(n), delete O(1)?
**A:** Insert in sorted position; delete from end

**Q4:** Best overall implementation?
**A:** Heap (O(log n) for both)

**Q5:** Applications of priority queue?
**A:** CPU scheduling, Dijkstra, Huffman, ER triage

**Q5:** Equal priorities - default tie-break?
**A:** FIFO (earlier inserted first) or implementation-defined
