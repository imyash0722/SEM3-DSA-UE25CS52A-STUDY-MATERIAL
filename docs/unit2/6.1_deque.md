# Unit 2: Deque (Double-Ended Queue)

---

## 17.1 Concept

**Deque** = Double-Ended Queue (pronounced "deck")

- **Two ends:** Front and Rear
- **Operations at BOTH ends:**
  - Add front, Add rear
  - Remove front, Remove rear
- **Implemented as:** Doubly Linked List (DLL)
  - Singly linked → one end would be O(n)

### Interface:
| Operation | Description |
|-----------|-------------|
| `add_front(x)` | Insert at front |
| `add_rear(x)` | Insert at rear |
| `remove_front()` | Remove from front |
| `remove_rear()` | Remove from rear |
| `front()` / `rear()` | Peek ends |
| `is_empty()` | Check empty |

---

## 17.2 Stack Using Deque (Composition)

### Concept: Composition over Inheritance
- Stack embeds Deque
- Stack methods **delegate** to Deque
- "Composition" = Embed one struct inside another

### Stack Structure:
```c
struct stack {
    dll_t list_;  // Embedded deque (DLL)
};
typedef struct stack stack_t;
```

### Stack Operations → Deque Delegation:

```c
void push(stack_t* s, int key) {
    add_in_begin(&s->list_, key);  // Add at front
}

int pop(stack_t* s) {
    return remove_in_begin(&s->list_);  // Remove from front
}

int is_empty_stack(stack_t* s) {
    return is_empty(&s->list_);
}

int is_full_stack(stack_t* s) {
    return is_full(&s->list_);
}

void init_stack(stack_t* s) { init(&s->list_); }
void deinit_stack(stack_t* s) { deinit(&s->list_); }
```

### Mapping:
| Stack | Deque (DLL) |
|-------|-------------|
| `push` | `add_in_begin` (front) |
| `pop` | `remove_in_begin` (front) |
| `is_empty` | `is_empty` |
| `is_full` | `is_full` |

---

## 17.3 Queue Using Deque

| Queue | Deque |
|-------|-------|
| `enqueue` | `add_in_end` (rear) |
| `dequeue` | `remove_in_begin` (front) |

---

## 17.4 C++ STL: Primary vs Secondary

| Category | Data Structures |
|----------|-----------------|
| **Primary** | `array`, `vector`, `deque`, `list` |
| **Secondary** | `stack`, `queue`, `priority_queue` |

**Pattern:** Secondary = wrapper/composition of primary

---

## Summary

| Aspect | Detail |
|--------|--------|
| **Deque** | Add/remove both ends |
| **Implementation** | Doubly Linked List |
| **Stack via Deque** | Composition; push/pop at front |
| **Queue via Deque** | Enqueue at rear, dequeue at front |
| **C++ STL** | Stack/Queue = adapters over deque/list |

## MCQ Practice

**Q1:** Deque implemented as?
**A:** Doubly Linked List (O(1) both ends)

**Q2:** Stack using deque: push → ?
**A:** add_in_begin (front)

**Q3:** Queue using deque: enqueue → ?
**A:** add_in_end (rear)

**Q4:** C++ STL: stack/queue are?
**A:** Secondary (adapters over primary containers)

**Q5:** Deque supports operations at how many ends?
**A:** Two (both front and rear)
