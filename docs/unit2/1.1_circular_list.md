# Unit 2: Circular Linked List

---

## 12.1 Concept

**Circular List:** Last node's `next` points back to first node (or header).

**Visual:**
```
[10] → [20] → [30] → [40]
 ↑                   |
 └───────────────────┘
```

**Real-world examples:** Music playlist (repeat), Round Robin scheduling, Josephus problem

---

## 12.2 Structure

```c
struct node {
    int key_;
    struct node *next_;
};
typedef struct node node_t;

struct clist {
    node_t *head_;  // Points to ONE node in the cycle
};
typedef struct clist clist_t;
```
- `head_` points to **any** node (convention: first inserted)
- Empty list: `head_ == NULL`

---

## 12.3 Operations

### Init:
```c
void init_clist(clist_t* l) { l->head_ = NULL; }
```

### Insert (after head):
```c
void insert(clist_t* l, int key) {
    node_t* temp = malloc(sizeof(node_t));
    temp->key_ = key;
    
    if (l->head_ == NULL) {
        temp->next_ = temp;       // Point to self!
        l->head_ = temp;
    } else {
        temp->next_ = l->head_->next_;
        l->head_->next_ = temp;   // Insert AFTER head
    }
}
```

### Empty List Insert:
```
Before: head = NULL
temp->next_ = temp;  // Self-loop
head = temp;

Result: head → [20] → (back to 20)
```

### Non-Empty Insert (after head):
```
Before: head → [20] → [40] → [60] → (back to 20)

temp->next_ = head->next_;  // temp->next = 40
head->next_ = temp;         // 20->next = 30

Result: head → [20] → [30] → [40] → [60] → (back to 20)
```

## 12.4 Display (do-while preferred)

```c
void disp_clist(clist_t* l) {
    if (!l->head_) { printf("Empty\n"); return; }
    
    node_t* pres = l->head_;
    printf("Circular List: ");
    do {
        printf("%d ", pres->key_);
        pres = pres->next_;
    } while (pres != l->head_);
    printf("\n");
}
```
**Why do-while?** Must execute at least once; condition checked after visiting head again.

## 12.5 Josephus Problem

### Problem:
- `n` people in circle, numbered 1..n
- Eliminate every `k`-th person
- Continue until 1 survivor

### Example: n=7, k=3
| Step | Counting | Eliminated | Remaining |
|------|----------|------------|-----------|
| 1 | 1→2→**3** | 3 | 1,2,4,5,6,7 |
| 2 | 4→5→**6** | 6 | 1,2,4,5,7 |
| 3 | 7→1→**2** | 2 | 1,4,5,7 |
| 4 | 4→5→**7** | 7 | 1,4,5 |
| 5 | 1→4→**5** | 5 | 1,4 |
| 6 | 1→4→**1** | 1 | 4 |
| 7 | **4** | - | **4 wins!** |

### Circular List Implementation:
```c
// Create circle of 1..n
clist_t circle = {NULL};
for (int i = n; i >= 1; --i) insert(&circle, i);

// Simulate
node_t* p = circle.head_;
while (p->next_ != p) {  // While >1 node
    // Move k-1 steps
    for (int i = 1; i < k; ++i) p = p->next_;
    // Eliminate next node
    node_t* victim = p->next_;
    p->next_ = victim->next_;
    free(victim);
    p = p->next_;  // Start from next
}
printf("Survivor: %d\n", p->key_);
```

## 12.6 Deinit (Free All)

```c
void free_clist(clist_t* l) {
    if (!l->head_) return;
    
    node_t* p = l->head_;
    do {
        node_t* next = p->next_;
        free(p);
        p = next;
    } while (p != l->head_);
    l->head_ = NULL;
}
```

## 12.7 Applications

| Application | Description |
|-------------|-------------|
| **Round Robin Scheduling** | Time-slice each process in cycle |
| **Music Playlist** | Auto-repeat |
| **Multiplayer Turns** | Next player = current->next |
| **Token Ring** | Token passes around |
| **Slideshow** | Loop images |

## 12.7 Doubly Circular List

```c
struct dnode {
    int key_;
    struct dnode *next_, *prev_;
};
```

- Each node has `next` AND `prev`
- Forms cycle in both directions
- Common in OS kernels (process lists)

## MCQ Practice

**Q1:** In circular list, `head` points to?
**A:** Any node (convention: first inserted)

**Q2:** Empty circular list `head` value?
**A:** `NULL`

**Q3:** Insert first node: `temp->next_ = temp;` Why?
**A:** Self-loop = cycle of 1

**Q4:** Insert after head: `temp->next_ = head->next_; head->next_ = temp;`
**A:** Inserts BETWEEN head and head->next

**Q5:** Josephus n=7, k=3 winner?
**A:** 4

**Q6:** Why do-while for display?
**A:** Must visit head at least once; condition checked after

**Q7:** Round Robin scheduling uses?
**A:** Circular list (time-slice each process)
