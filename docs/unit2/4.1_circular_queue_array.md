# Unit 2: Circular Queue (Array Implementation)

---

## 15.1 Problem with Linear Array Queue

```
[10] [20] [30] [  ] [  ]
 ↑           ↑
front=0     rear=2
```
- After dequeues: `front` advances, empty space at front
- After enqueues: `rear` hits `MAXSIZE-1` → "full" (even if space at front!)
- **Solution:** Circular array with modulo arithmetic

---

## 15.2 Circular Array Concept

```
Physical:  [  ][  ][  ][  ][  ]
Index:       0   1   2   3   4
             ↑           ↑
           front=4    rear=3
             (wrap)
```

**Modulo Arithmetic:**
```c
i = (i + 1) % MAXSIZE;  // Increment with wrap
i = (i - 1 + MAXSIZE) % MAXSIZE;  // Decrement with wrap
```

---

## 15.3 Structure

```c
#define MAXSIZE 5

struct queue {
    int key_[MAXSIZE];
    int front_;  // Index of front element
    int rear_;   // Index of rear element
};
typedef struct queue queue_t;
```

---

## 15.4 Key Design: Waste One Slot

**Problem:** `front == rear` means both empty AND full!

**Solution:** Always keep **one empty slot** to distinguish.

| Condition | Meaning |
|-----------|---------|
| `front == rear` | **Empty** |
| `(rear + 1) % MAXSIZE == front` | **Full** |

**Cost:** One wasted slot (e.g., MAXSIZE=5 → holds 4 elements)

---

## 15.5 Operations

### Init/Deinit:
```c
void init_queue(queue_t* q) { q->front_ = q->rear_ = 0; }
void deinit_queue(queue_t* q) { q->front_ = q->rear_ = 0; }
```

### Enqueue:
```c
void enque(queue_t* q, int key) {
    int next_rear = (q->rear_ + 1) % MAXSIZE;
    
    if (next_rear == q->front_) {  // Full?
        printf("queue full\n");
        return;
    }
    
    q->rear_ = next_rear;
    q->key_[q->rear_] = key;
}
```

**Note:** Increment rear **first**, then check full.

### Dequeue:
```c
int deque(queue_t* q) {
    if (q->front_ == q->rear_) return 0;  // Empty
    
    int next_front = (q->front_ + 1) % MAXSIZE;
    int key = q->key_[next_front];
    q->front_ = next_front;
    return key;
}
```

**Note:** Check empty **before** incrementing front.

---

## 15.6 Empty/Full Checks

```c
// Called BEFORE deque (before incrementing front)
int is_empty(queue_t* q) {
    return q->front_ == q->rear_;
}

// Called AFTER enque (after incrementing rear)
int is_full(queue_t* q) {
    return (q->rear_ + 1) % MAXSIZE == q->front_;
}
```

| Function | Called | Check |
|----------|--------|-------|
| `is_empty` | Before dequeue | `front == rear` |
| `is_full` | After enqueue | `(rear+1)%MAX == front` |

## MCQ Practice

**Q1:** MAXSIZE=5, how many elements can queue hold?
**A:** 4 (one slot wasted)

**Q2:** `front=2, rear=2` → Empty or Full?
**A:** Empty

**Q3:** `front=3, rear=2` (MAX=5) → Full?
**A:** Yes, `(2+1)%5 = 3 == front`

**Q4:** Enqueue steps: increment rear, check full, assign?
**A:** Increment rear → check full → if not full, store

**Q4:** Dequeue steps: check empty, increment front, return?
**A:** Check empty → increment front → return value

**Q5:** Why waste one slot?
**A:** To distinguish empty (`f==r`) from full (`f==r` would be ambiguous)
