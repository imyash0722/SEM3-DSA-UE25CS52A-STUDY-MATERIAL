## Study Strategy

1. **Start with Unit 1 Theory** - Master ADT concepts, pointers, memory management
2. **Practice Unit 1 Examples** - Write and trace every program
3. **Unit 2 Theory** - Compare queue/PQ implementations (table on theory page)
4. **Unit 3 Theory** - Focus on BST operations, heapify, AVL rotations, graph representations
5. **Review Quick Reference** - Use checklist before exams

## Key Programs to Master

| Program | Unit | Concepts |
|---------|------|----------|
| Linked List (Ordered + Header Node) | 1 | ADT, pointer manipulation, makefiles |
| Stack Applications (Parenthesis, Postfix, Infix→Postfix) | 1 | Stack ADT, expression parsing |
| Circular Array Queue | 2 | Modulo arithmetic, O(1) operations |
| Priority Queue (all 5 implementations) | 2 | Time/space trade-offs |
| BST Insert/Search/Delete (Dynamic + Array) | 3 | Recursive on nodes |
| Heap (Build, Insert, Delete Max, Heapsort) | 3 | Complete tree, O(log n) |
| AVL Rotations (LL, RR, LR, RL) | 3 | Balance factor, rotations |
| Graph BFS/DFS/Dijkstra | 3 | Queue/Stack/PQ applications |
