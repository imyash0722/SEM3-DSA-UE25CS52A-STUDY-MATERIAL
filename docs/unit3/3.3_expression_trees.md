# Unit 3: Expression Trees

## 4.1 Concept

An **expression tree** represents an arithmetic expression where:
- **Leaves** = operands (operands assumed to be single digits)
- **Internal nodes** = operators (+, -, *, /)

**Algorithm:** Two phases
1. **Phase 1:** Construct expression tree from postfix expression
2. **Phase 2:** Evaluate the expression tree

---

## 4.2 Phase 1: Construct Expression Tree (Postfix → Tree)

**Input:** Postfix expression (e.g., `34+2*`)
**Data Structure:** Stack of tree nodes

**Algorithm:**
```
Scan postfix left to right:
  If operand:
    - Create tree node
    - Push to stack
  If operator:
    - Pop two nodes (first pop = right, second = left)
    - Create new node with operator as key
    - Attach popped nodes as left/right subtrees
    - Push new node back to stack
```
At end: Stack has exactly ONE node = root of expression tree

---

## 4.3 Phase 2: Evaluate Expression Tree

**Algorithm (Recursive):**
```
If node is leaf (both children NULL):
    Return operand value (root->ch_ - '0')
Else:
    left_val  = eval(left subtree)
    right_val = eval(right subtree)
    Apply operator at root to (left_val, right_val)
```

---

## 4.4 Implementation Details

### Node Structure
```c
#define MAXSIZE 100

struct node {
    char ch_;           // operand digit or operator
    struct node *left_;
    struct node *right_;
};
typedef struct node node_t;
```

### Stack of Tree Nodes
```c
struct stack {
    node_t* key_[MAXSIZE];
    int top_;
};
typedef struct stack stack_t;
```

### Stack Interface
```c
void init_stack(stack_t *ptr_stack);
void deinit_stack(stack_t *ptr_stack);
void push_operand(stack_t *ptr_stack, char ch);
void push_operator(stack_t *ptr_stack, char ch);
node_t* pop(stack_t *ptr_stack);
int is_empty(stack_t *ptr_stack);
int is_full(stack_t *ptr_stack);
int eval(stack_t *ptr_stack);  // Pops root and evaluates
```

## 4.5 Core Implementation

### Create Node
```c
static node_t* create_node(char ch) {
    node_t *temp = malloc(sizeof(node_t));
    if(temp == NULL) { printf("memory full\n"); exit(1); }
    temp->ch_ = ch;
    temp->left_ = temp->right_ = NULL;
    return temp;
}
```

### Push Operand
```c
void push_operand(stack_t *ptr_stack, char ch) {
    if(!is_full(ptr_stack)) {
        node_t* temp = create_node(ch);
        ptr_stack->key_[++ptr_stack->top_] = temp;
    } else {
        printf("stack full; cannot push\n");
    }
}
```

### Push Operator (Key!)
```c
void push_operator(stack_t *ptr_stack, char ch) {
    if(!is_full(ptr_stack)) {
        node_t* temp = create_node(ch);
        temp->right_ = pop(ptr_stack);  // First pop = RIGHT child
        temp->left_ = pop(ptr_stack);   // Second pop = LEFT child
        ptr_stack->key_[++ptr_stack->top_] = temp;
    }
}
```
**Note:** First pop becomes RIGHT child, second becomes LEFT (stack is LIFO)

### Pop
```c
node_t* pop(stack_t *ptr_stack) {
    if(!is_empty(ptr_stack))
        return ptr_stack->key_[ptr_stack->top_--];
    else {
        printf("stack empty; cannot pop\n");
        return '\0';
    }
}
```

### Evaluation
```c
int eval_recursive(node_t* root) {
    int left, right;
    if(root->left_ == NULL && root->right_ == NULL)
        return root->ch_ - '0';  // Convert char digit to int
    left = eval_recursive(root->left_);
    right = eval_recursive(root->right_);
    switch(root->ch_) {
        case '+': return left + right;
        case '-': return left - right;
        case '*': return left * right;
        case '/': return left / right;
    }
    return 0;
}

int eval(stack_t *ptr_stack) {
    return eval_recursive(pop(ptr_stack));  // Pop root and evaluate
}
```

## 4.6 Example Trace

**Postfix:** `34+2*`

**Stack trace:**
| Input | Stack (bottom→top) | Action |
|-------|-------------------|--------|
| `3` | `[3]` | Push operand 3 |
| `4` | `[3, 4]` | Push operand 4 |
| `+` | `[+]` | Pop 4,3 → create + node with left=3, right=4 → push |
| `2` | `[+, 2]` | Push operand 2 |
| `*` | `[*]` | Pop 2,+ → create * with left=+, right=2 → push |

**Result:** Stack has `*` at root
```
    *
   / \
  +   2
 / \
3   4
```

**Evaluation:**
```
eval(+): 3+4 = 7
eval(*): 7*2 = 14
```

## 4.7 Limitation & Extension

**Current limitation:** Operands = single characters (digits)

**Extension:** Use `union` for multi-digit operands:
```c
struct node {
    int is_operator;  // 1=operator, 0=operand
    union {
        int operand;
        char operator;
    } value;
    struct node *left_;
    struct node *right_;
};
```
No discriminator needed if operands are only in leaves.
