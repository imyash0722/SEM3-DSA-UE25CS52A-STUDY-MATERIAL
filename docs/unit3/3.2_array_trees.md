# Unit 3: Array Implementation of Binary Trees

## 3.1 Why Array Implementation?

**Node-based (dynamic memory):**
- Uses pointers (left_, right_)
- Flexible size
- Extra memory for pointers

**Array-based:**
- No pointers needed
- No extra storage
- Easy to determine empty/full
- Simple traversal (array or tree)
- No memory waste (complete binary tree)

---

## 3.2 Two Array Mapping Approaches

### 1. Implicit Mapping (Complete Binary Trees Only)

**0-indexed:**
```
Parent(i) = floor((i-1)/2)
Left(i)   = 2i + 1
Right(i)  = 2i + 2
```

**1-indexed (textbook preferred):**
```
Parent(i) = i/2
Left(i)   = 2i
Right(i)  = 2i + 1
```

**Limitation:** Only works for **complete binary trees** (all levels full, last level filled left-to-right). For sparse trees, many array slots wasted.

---

### 2. Explicit Index Mapping (General Binary Trees)

Each node stores:
- `key_` (data)
- `left_` (index of left child, -1 if none)
- `right_` (index of right child, -1 if none)

```c
#define MAXSIZE 200

struct node {
    int key_;
    int left_;   // index of left child
    int right_;  // index of right child
};
typedef struct node node_t;

struct tree {
    int root_;      // index of root (-1 = empty)
    int count_;     // number of elements / next free slot
    node_t elem_[MAXSIZE];
};
typedef struct tree tree_t;
```

**Tree state:**
- Empty: `root_ = -1`, `count_ = 0`
- After insert: `root_` = index, `count_` increments

---

## 3.3 Core Operations

### Init / Deinit
```c
void init(tree_t *ptr_tree) {
    ptr_tree->root_ = -1;
    ptr_tree->count_ = 0;
}

void deinit(tree_t *ptr_tree) {
    ptr_tree->root_ = -1;
    ptr_tree->count_ = 0;
}
```

### Inorder Traversal
```c
static void disp_recursive(node_t elem[], int temp) {
    if(temp != -1) {
        disp_recursive(elem, elem[temp].left_);
        printf("%d ", elem[temp].key_);
        disp_recursive(elem, elem[temp].right_);
    }
}

void disp(tree_t *ptr_tree) {
    printf("Tree : ");
    disp_recursive(ptr_tree->elem_, ptr_tree->root_);
    printf("\n");
}
```

### Insert
```c
void insert(tree_t *ptr_tree, int key) {
    if(ptr_tree->count_ == MAXSIZE) { printf("tree full\n"); exit(1); }
    
    int temp = ptr_tree->count_++;
    ptr_tree->elem_[temp].key_ = key;
    ptr_tree->elem_[temp].left_ = ptr_tree->elem_[temp].right_ = -1;
    ptr_tree->root_ = insert_recursive(ptr_tree->elem_, ptr_tree->root_, temp);
}

static int insert_recursive(node_t elem[], int root, int temp) {
    if(root == -1) return temp;
    else if(elem[root].key_ > elem[temp].key_)
        elem[root].left_ = insert_recursive(elem, elem[root].left_, temp);
    else
        elem[root].right_ = insert_recursive(elem, elem[root].right_, temp);
    return root;
}
```

## 3.4 Additional Operations

### Number of Nodes
```c
int number_of_nodes_recursive(node_t elem[], int temp) {
    if(temp == -1) return 0;
    return 1 + number_of_nodes_recursive(elem, elem[temp].left_)
             + number_of_nodes_recursive(elem, elem[temp].right_);
}
```

### Number of Leaves
```c
int number_of_leaves_recursive(node_t elem[], int temp) {
    if(temp == -1) return 0;
    if(elem[temp].left_ == -1 && elem[temp].right_ == -1) return 1;
    return number_of_leaves_recursive(elem, elem[temp].left_)
         + number_of_leaves_recursive(elem, elem[temp].right_);
}
```

### Compare Two Trees
```c
int are_same_recursive(node_t elem1[], int root1, node_t elem2[], int root2) {
    if(root1 == -1 && root2 == -1) return 1;
    if(root1 == -1 || root2 == -1) return 0;
    return elem1[root1].key_ == elem2[root2].key_ &&
           are_same_recursive(elem1, elem1[root1].left_, elem2, elem2[root2].left_) &&
           are_same_recursive(elem1, elem1[root1].right_, elem2, elem2[root2].right_);
}
```

### Copy Tree (Iterative)
```c
void copy(tree_t* ptr_src, tree_t* ptr_dst) {
    ptr_dst->root_ = ptr_src->root_;
    ptr_dst->count_ = ptr_src->count_;
    for(int i = 0; i < MAXSIZE; ++i)
        ptr_dst->elem_[i] = ptr_src->elem_[i];
}
```

## 3.5 Traversals (All Three)

```c
// Inorder: Left → Root → Right
static void disp_inorder_recursive(node_t elem[], int temp) {
    if(temp != -1) {
        disp_inorder_recursive(elem, elem[temp].left_);
        printf("%d ", elem[temp].key_);
        disp_inorder_recursive(elem, elem[temp].right_);
    }
}

// Preorder: Root → Left → Right
static void disp_preorder_recursive(node_t elem[], int temp) {
    if(temp != -1) {
        printf("%d ", elem[temp].key_);
        disp_preorder_recursive(elem, elem[temp].left_);
        disp_preorder_recursive(elem, elem[temp].right_);
    }
}

// Postorder: Left → Right → Root
static void disp_postorder_recursive(node_t elem[], int temp) {
    if(temp != -1) {
        disp_postorder_recursive(elem, elem[temp].left_);
        disp_postorder_recursive(elem, elem[temp].right_);
        printf("%d ", elem[temp].key_);
    }
}
```

## 3.6 Free Slot Management (Memory Manager)

**Problem:** On deletion, slots become available at different locations.

**Solution:** Maintain a **free list** of available slots:
- On insert: take from free list (or use `count_` if empty)
- On delete: add slot back to free list

```c
// Simplified: use count_ as next free slot (no memory manager)
int temp = ptr_tree->count_++;  // Next free slot
```
