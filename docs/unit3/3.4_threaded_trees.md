# Unit 3: Threaded Binary Trees

## 5.1 Motivation

**Problem:** In a node-based tree of n nodes:
- Each node has 2 pointers (left_, right_)
- Only n-1 edges exist → n+1 pointers are NULL (grounded)
- **Waste:** n+1 null pointers

**Solution:** Replace NULL pointers with **threads** (pointers to inorder predecessor/successor)

---

## 5.2 Thread Concept

| Thread Type | Points To |
|-------------|-----------|
| **Left thread (lthread=1)** | Inorder predecessor |
| **Right thread (rthread=1)** | Inorder successor |
| **Structural pointer (lthread/rthread=0)** | Left/right child |

**Node Structure:**
```c
struct node {
    int key_;
    struct node *left_;
    struct node *right_;
    int lthread_;  // 1 = thread, 0 = structural
    int rthread_;  // 1 = thread, 0 = structural
};
typedef struct node node_t;
```

**Leftmost node's left thread** and **rightmost node's right thread** may point to root or be grounded.

---

## 5.3 Insertion in Threaded BST

### Create Node
```c
static node_t* create_node(int key) {
    node_t *temp = malloc(sizeof(node_t));
    if(temp == NULL) { printf("no more memory\n"); exit(1); }
    temp->key_ = key;
    temp->left_ = temp->right_ = NULL;
    temp->lthread_ = temp->rthread_ = 1;  // New node: both are threads
    return temp;
}
```

### Insert Algorithm
```c
void insert(tree_t *ptr_tree, int key) {
    ptr_tree->root_ = insert_key(ptr_tree->root_, key);
}

static node_t* insert_key(node_t* root, int key) {
    node_t *temp = create_node(key);
    node_t *parent = NULL;
    node_t *curr = root;
    
    // Find insertion position
    while(curr != NULL) {
        parent = curr;
        if(key < curr->key_) {
            if(curr->lthread_ == 0) curr = curr->left_;  // Structural
            else break;  // Thread → leaf position
        } else {
            if(curr->rthread_ == 0) curr = curr->right_;
            else break;
        }
    }
    
    // First node
    if(parent == NULL) return temp;
    
    // Insert as left child
    if(key < parent->key_) {
        temp->left_ = parent->left_;   // Inherit parent's predecessor thread
        temp->right_ = parent;         // Parent is successor
        parent->left_ = temp;          // Attach as structural child
        parent->lthread_ = 0;          // No longer a thread
    }
    // Insert as right child
    else {
        temp->right_ = parent->right_; // Inherit parent's successor thread
        temp->left_ = parent;          // Parent is predecessor
        parent->right_ = temp;
        parent->rthread_ = 0;
    }
    return root;
}
```

**Key Insight:** New node inherits parent's thread and points to parent as predecessor/successor.

## 5.4 Inorder Traversal (Iterative, No Stack!)

### Find Leftmost Node
```c
static node_t *leftmost(node_t *temp) {
    if(temp == NULL) return NULL;
    while(temp->lthread_ == 0)  // While structural
        temp = temp->left_;
    return temp;
}
```

### Inorder Traversal
```c
static void inorder(node_t *root) {
    node_t *temp = leftmost(root);
    while(temp != NULL) {
        printf("%d ", temp->key_);  // Visit
        
        if(temp->rthread_ == 1)     // Thread to successor
            temp = temp->right_;
        else                        // Structural right child
            temp = leftmost(temp->right_);
    }
}

void disp(tree_t *ptr_tree) {
    printf("Tree : ");
    inorder(ptr_tree->root_);
    printf("\n");
}
```

**Algorithm:**
1. Start at leftmost node
2. Visit current node
3. If right is thread → follow thread to successor
4. If right is structural → go to right child, then find its leftmost
4. Repeat until NULL

**Space Complexity:** O(1) — no stack, no recursion!

## 5.5 Example Trace

**Insert:** 30, 20, 40, 10, 25

**Resulting Threaded Tree:**
```
        30
       /  \
     20    40
    /  \
   10  25
```

**Inorder traversal sequence:** 10 → 20 → 25 → 30 → 40

**Traversal steps:**
1. Start at leftmost (10)
2. Visit 10 → right is thread → follow to 20
4. Visit 20 → right is structural → go to 25 (leftmost of 20's right)
6. Visit 25 → right is thread → follow to 30
8. Visit 30 → right is structural → go to 40 (leftmost of 30's right)
10. Visit 40 → right is thread/NULL → stop
