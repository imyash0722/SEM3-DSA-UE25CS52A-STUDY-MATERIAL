# Unit 3: General Trees & Binary Search Trees

## 3.1 Tree Fundamentals

### Definition
A **tree** is a non-linear data structure that is an **acyclic, connected graph**.
- A tree of n nodes has n-1 branches/edges
- Adding an edge creates a cycle; removing an edge breaks connectivity

### General Tree (Recursive Definition)
A general tree is either:
1. **Empty**, OR
2. Has a **root** followed by number of **subtrees**

### Terminology
| Term | Definition |
|------|------------|
| **Root** | Topmost node |
| **Node** | An element in the tree |
| **Internal Node** | Node with at least one child |
| **Leaf** | Node with no children |
| **Branch/Edge** | Connection between parent and child |
| **Path** | Sequence of nodes connected by edges |
| **Ancestor** | Node on path from root to given node |
| **Descendant** | Node below given node |
| **Parent/Child** | Direct connection |
| **Siblings** | Nodes sharing same parent |
| **Grandparent/Grandchild** | Two levels apart |
| **Uncle** | Sibling of parent |
| **Height** | Longest path from node to leaf |
| **Depth** | Distance from root (root depth = 0) |
| **Level** | All nodes at same depth |
| **Degree** | Number of children |

### Properties
- Acyclic (no cycles)
- Connected (path between every pair of nodes)
- n nodes → n-1 edges
- Add edge → cycle formed
- Remove edge → connectivity lost

## 3.2 Binary Tree

### Definition
A **binary tree** is a tree where every node has **at most two children** — distinguished as **left child** and **right child**.

**Recursive Definition:**
- Empty tree, OR
- Root node + two disjoint binary trees (left subtree, right subtree)

### Example Tree
```
        A (root)
       / \
      B   C
     / \   \
    D   E   F
```
- Leaves: D, E, F
- Internal nodes: A, B, C

### Binary Tree ADT Operations
| Operation | Description |
|-----------|-------------|
| `Create()` | Create empty tree |
| `Destroy()` | Remove tree |
| `root()` | Return root |
| `parent(p)` | Return parent of p |
| `left(p)` | Return left child |
| `right(p)` | Return right child |
| `isLeaf(p)` | Test if p is leaf |
| `component(p)` | Return data at p |
| `addRoot(x)` | Create root with x |
| `addLeft(p, x)` | Add x as left child of p |
| `addRight(p, x)` | Add x as right child of p |
| `remove(p)` | Remove p and its subtree |
| `size()` | Return number of nodes |
| `is_empty()` | Test if empty |
| `is_full()` | Check if can add |
| `height()` | Return height |

### Traversals (Recursive)
**Inorder (Left → Root → Right):**
```
D B E A C F
```

**Preorder (Root → Left → Right):**
```
A B D E C F
```

**Postorder (Left → Right → Root):**
```
D E B F C A
```

## 3.3 Binary Search Tree (BST)

### Property
- Every component has a **key**
- Components arranged by key:
  - If key < root → go to **left subtree**
  - If key > root → go to **right subtree**
- **Insertion always happens as a leaf**

### Node Structure
```c
struct node {
    int key_;
    struct node *left_;
    struct node *right_;
};
typedef struct node node_t;

struct tree {
    node_t *root_;
};
typedef struct tree tree_t;
```

### Core Operations

#### Init / Deinit
```c
void init(tree_t *ptr_tree) { ptr_tree->root_ = NULL; }

void deinit(tree_t *ptr_tree) {
    deinit_recursive(ptr_tree->root_);
    ptr_tree->root_ = NULL;
}

static void deinit_recursive(node_t* root) {
    if(root) {
        deinit_recursive(root->left_);
        deinit_recursive(root->right_);
        free(root);
    }
}
```

#### Inorder Traversal (Sorted Output)
```c
void disp_inorder(tree_t *ptr_tree) {
    printf("Tree inorder: ");
    disp_recursive_inorder(ptr_tree->root_);
    printf("\n");
}

static void disp_recursive_inorder(node_t* temp) {
    if(temp) {
        disp_recursive_inorder(temp->left_);
        printf("%d ", temp->key_);
        disp_recursive_inorder(temp->right_);
    }
}
```

#### Insert
```c
void insert(tree_t *ptr_tree, int key) {
    node_t *temp = malloc(sizeof(node_t));
    temp->key_ = key; temp->left_ = temp->right_ = NULL;
    ptr_tree->root_ = insert_recursive(ptr_tree->root_, temp);
}

static node_t* insert_recursive(node_t* root, node_t* temp) {
    if(root == NULL) return temp;
    else if(root->key_ > temp->key_)
        root->left_ = insert_recursive(root->left_, temp);
    else
        root->right_ = insert_recursive(root->right_, temp);
    return root;
}
```

#### Search (Returns Node Pointer)
```c
node_t* search_recursive(node_t* root, int key) {
    if(root == NULL) return NULL;
    else if(key == root->key_) return root;
    else if(key < root->key_) return search_recursive(root->left_, key);
    else return search_recursive(root->right_, key);
}
```

#### Delete Key (4 Cases)
```c
void delete_key(tree_t *ptr_tree, int key) {
    ptr_tree->root_ = delete_key_recursive(ptr_tree->root_, key);
}

node_t* delete_key_recursive(node_t* root, int key) {
    if(root == NULL) return NULL;
    
    if(key < root->key_)
        root->left_ = delete_key_recursive(root->left_, key);
    else if(key > root->key_)
        root->right_ = delete_key_recursive(root->right_, key);
    else { // Found the node
        // Case 1: Leaf
        if(root->left_ == NULL && root->right_ == NULL) {
            free(root); return NULL;
        }
        // Case 2: No left subtree
        else if(root->left_ == NULL) {
            node_t* temp = root->right_; free(root); return temp;
        }
        // Case 3: No right subtree
        else if(root->right_ == NULL) {
            node_t* temp = root->left_; free(root); return temp;
        }
        // Case 4: Both subtrees - use inorder successor
        else {
            node_t* temp = inorder_successor(root->right_);
            root->key_ = temp->key_;
            root->right_ = delete_key_recursive(root->right_, temp->key_);
        }
    }
    return root;
}

node_t* inorder_successor(node_t* root) {
    node_t* temp = root;
    while(temp->left_ != NULL) temp = temp->left_;
    return temp;
}
```

## 3.4 Tree Queries (Recursive Patterns)

| Query | Base Case | Recursive Case |
|-------|-----------|----------------|
| **Count nodes** | NULL → 0 | 1 + L + R |
| **Count leaves** | NULL → 0 | Leaf → 1, else L + R |
| **Height** | NULL → -1 | 1 + max(L, R) |
| **Search** | NULL → false | key == root || L || R |
| **Copy tree** | NULL → NULL | new node with copied subtrees |
| **Compare trees** | Both NULL → true | Keys equal && L same && R same |

## 3.5 Tree Storage & Reconstruction

**Key Insight:** A single traversal does NOT uniquely define a tree!
- Example: Inorder `A B C` → 5 possible trees

**Two traversals uniquely define a tree:**
- **Inorder + Postorder** (or Inorder + Preorder)

**Reconstruction Algorithm:**
1. Last in postorder = root
2. Find root in inorder → splits into left/right subtrees
3. Recurse on subtrees

**Example:**
```
Inorder:   D B H E A F C G J I
Postorder: D H E B F J I G C A

Root = A (last in postorder)
Left inorder:  D B H E
Right inorder: F C G J I
```
