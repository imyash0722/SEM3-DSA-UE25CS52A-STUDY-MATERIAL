# Unit 3: Heaps & Priority Queues

## 6.1 Heap Definition

A **max-heap** is a binary tree with two properties:
1. **Complete binary tree:** All levels filled except possibly last; last level filled left-to-right
2. **Parental dominance (max-heap):** Key at each node ≥ keys of its children

**Min-heap:** Same but parent ≤ children

**Note:** NOT a search tree — no ordering between left/right subtrees

---

## 6.2 Array Implementation (1-indexed)

```c
#define MAXSIZE 200

struct heap {
    int key_[MAXSIZE];
    int n_;        // number of elements
};
typedef struct heap heap_t;
```

**Index Relationships (1-indexed):**
| Operation | Formula |
|-----------|---------|
| Parent(i) | i/2 |
| Left(i) | 2i |
| Right(i) | 2i+1 |

**Advantages:**
- No pointers
- No extra storage
- O(1) empty/full check
- Simple traversal (array or tree)
- No wasted memory (complete tree)

---

## 6.3 Core Operations

### Init / Deinit
```c
void init(heap_t *ptr_heap) { ptr_heap->n_ = 0; }
void deinit(heap_t *ptr_heap) { ptr_heap->n_ = 0; }
```

### Display
```c
void disp(heap_t *ptr_heap) {
    printf("Heap: ");
    for(int i = 1; i <= ptr_heap->n_; ++i)
        printf("%d ", ptr_heap->key_[i]);
    printf("\n");
}
```

## 6.4 Build Heap (Bottom-Up Heapify)

### Heapify
**Precondition:** Left and right subtrees of node at `pos` are already heaps
**Operation:** "Sink" root down to restore heap property

```c
static void heapify(int a[], int n, int pos) {
    int i = pos;
    int j = 2 * i;          // left child
    int val = a[i];         // save root value
    int is_heap = 0;
    
    while(j <= n && !is_heap) {
        // Choose larger child
        if(j + 1 <= n && a[j+1] > a[j])
            ++j;  // right child is larger
        
        if(a[j] > val) {
            a[i] = a[j];    // move child up
            i = j;          // move down
            j = 2 * i;
        } else {
            is_heap = 1;    // heap property satisfied
        }
    }
    a[i] = val;  // place saved value at final position
}
```

### Build Heap
```c
void build_heap(heap_t *ptr_heap, int a[], int n) {
    ptr_heap->n_ = n;
    for(int i = 1; i <= n; ++i)
        ptr_heap->key_[i] = a[i];
    for(int i = n / 2; i >= 1; --i) {
        heapify(ptr_heap->key_, ptr_heap->n_, i);
        disp(ptr_heap);  // shows each step
    }
}
```

**Why start at n/2?** Nodes > n/2 are leaves (already heaps)

**Time Complexity:** O(n) — not O(n log n)!

## 6.5 Insert & Delete Max

### Insert (O(log n))
```c
void insert(heap_t *ptr_heap, int key) {
    int pos = ++ptr_heap->n_;
    if(pos > MAXSIZE) { printf("heap full\n"); exit(1); }
    ptr_heap->key_[pos] = key;
    
    // Bubble up
    while(pos > 1 && ptr_heap->key_[pos] > ptr_heap->key_[pos/2]) {
        swap(&ptr_heap->key_[pos], &ptr_heap->key_[pos/2]);
        pos = pos / 2;
    }
}
```

### Delete Max (O(log n))
```c
int delete_max(heap_t *ptr_heap) {
    if(ptr_heap->n_ == 0) { printf("heap empty\n"); exit(1); }
    int res = ptr_heap->key_[1];
    ptr_heap->key_[1] = ptr_heap->key_[ptr_heap->n_];
    heapify(ptr_heap->key_, --ptr_heap->n_, 1);
    return res;
}
```

### Peek Max (O(1))
```c
int peek_max(heap_t *ptr_heap) {
    return ptr_heap->key_[1];
}
```

**Complexity:** Both insert and delete_max are O(log n) — proportional to log₂ n

## 6.6 Priority Queue Using Heap (Composition)

```c
struct node { int key_; struct node* next_; };
typedef struct node node_t;

struct queue {
    heap_t q_;  // Composition: PQ has-a heap
};
typedef struct queue queue_t;

void init_queue(queue_t *ptr_queue) { init(&ptr_queue->q_); }
void deinit_queue(queue_t *ptr_queue) { deinit(&ptr_queue->q_); }
void enqueue(queue_t *ptr_queue, int key) { insert(&ptr_queue->q_, key); }
int dequeue(queue_t *ptr_queue) { return delete_max(&ptr_queue->q_); }
int is_empty(queue_t *ptr_queue) { return ptr_queue->q_.n_ == 0; }
int is_full(queue_t *ptr_queue) { return ptr_queue->q_.n_ == MAXSIZE; }
```

## 6.7 Heapsort (Theoretical)

```c
void heapsort(int a[], int n) {
    heap_t h; build_heap(&h, a, n);
    for(int i = n; i >= 1; --i)
        a[i] = delete_max(&h);  // Extract max to end
}
```
- Time: O(n log n)
- Space: O(1) extra
- **Not cache-friendly** → not used in standard libraries

| Use Case | Description |
