# Unit 3: Graphs

## 9.1 Definition

A **graph** G = (V, E) where:
- **V** = set of vertices (nodes)
- **E** = set of edges (pairs of vertices)

**Example:** V = {A, B, C, D, E, F, G, H}, E = {AB, AC, BC, BD, CE, DE, DF, FG, EG, GH, FH}

|V| = 8, |E| = 11

---

## 9.2 Types of Graphs

| Type | Description |
|------|-------------|
| **Undirected** | Edge (u,v) = (v,u) |
| **Directed (Digraph)** | Edge (u,v) ≠ (v,u) |
| **Weighted** | Each edge has weight (distance, time, cost) |
| **Simple** | No self-loops, no multi-edges |

---

## 9.3 Terminology

| Term | Definition |
|------|------------|
| **Vertex** | Object in graph (e.g., A) |
| **Edge** | Connection between vertices (e.g., AB) |
| **Adjacent** | Vertices connected directly by an edge |
| **Incident** | Edge is incident on its endpoints |
| **Degree** | Number of incident edges (undirected) |
| **In-degree** | Edges entering vertex (directed) |
| **Out-degree** | Edges leaving vertex (directed) |
| **Path** | Sequence of vertices joined by edges |
| **Path length** | Number of edges in path |
| **Cycle** | Path returning to start without repeating vertices |
| **Connected graph** | Every vertex reachable from every other |
| **Connected component** | Maximal connected subgraph |
| **Complete graph** | Every pair of vertices connected |

**Handshaking Lemma:** For undirected graph, Σ deg(v) = 2|E|

## 9.4 Representations

### A. Adjacency Matrix
- V × V array A
- A[i][j] = 1 if edge exists, 0 otherwise
- Undirected → symmetric
- **Space:** O(V²)
- **Edge check:** O(1)

### B. Adjacency List
- Array of lists: one list per vertex
- Each list contains neighbors
- **Space:** O(V + E) — node per vertex + node per edge
- **Edge check:** O(degree)

**Example:**
```
A → B, C
B → A, C, D
C → A, B, E
D → B, E, F
E → C, D, G
F → D, G, H
G → E, F, H
H → F, G
```

## 9.5 Königsberg Bridge Problem

**Problem:** 7 bridges, traverse each exactly once and return to start

**Euler's Solution:** For a closed trail (start = end), every vertex must have **even degree**. Königsberg has degrees 3,3,3,5 → **impossible**.

| Graph Type | Condition |
|------------|-----------|
| **Eulerian** (closed trail) | All vertices even degree |
| **Hamiltonian** (visit each vertex once) | No simple condition (NP-complete) |

## 9.6 Applications

| Domain | Vertices | Edges | Use |
|--------|----------|-------|-----|
| **Road Networks** | Cities/intersections | Roads | Shortest path, routing |
| **Social Networks** | People | Friendships/follows | Communities, influence |
| **Computer Networks** | Routers/computers | Links | Routing, max flow |
| **Course Prerequisites** | Courses | "Must take before" | Topological sort |
| **Software Dependencies** | Modules/files | Imports/requires | Build order |
| **Airline/Logistics** | Airports/warehouses | Routes | MST, max flow |
| **Web Pages** | Pages | Hyperlinks | PageRank |
| **Project Scheduling** | Tasks | Precedence | Critical path |

## 9.6 Graph ADT Operations

| Operation | Purpose |
|-----------|---------|
| `create_graph()` | Create empty graph |
| `add_vertex(v)` | Insert vertex |
| `remove_vertex(v)` | Remove vertex + incident edges |
| `add_edge(u, v)` | Add edge (u,v) |
| `remove_edge(u, v)` | Remove edge |
| `has_vertex(v)` | Check if v exists |
| `has_edge(u, v)` | Check if edge exists |
| `get_neighbors(v)` | Return adjacent vertices |
| `degree(v)` | Return degree of v |
| `display_graph()` | Show vertices and edges |
| `destroy_graph()` | Release resources |
