## 11.1 Parentheses Matching (Single Type)

### Problem:
Check if expression has well-formed parentheses `(` and `)`.

### Algorithm:
1. Initialize empty stack
2. Scan string left to right
3. `(` → push placeholder
4. `)` → pop; if stack empty → invalid
5. End → stack must be empty

### Code:
```c
int is_valid = 1;
char str[MAXSIZE + 1];
scanf("%s", str);

stack_t s; init_stack(&s);
char ch, *p = str;

while (is_valid && (ch = *p++) != '\0') {
    if (ch == '(') {
        push(&s, 'x');  // placeholder
    }
    else if (ch == ')') {
        if (!is_empty(&s))
            pop(&s);
        else
            is_valid = 0;  // ) before (
    }
}

if (is_valid && is_empty(&s))
    printf("Well formed\n");
else
    printf("Not well formed\n");
```

### Trace:
| Input | Stack After | Valid? |
|-------|-------------|--------|
| `(` | `[x]` | ✓ |
| `(` | `[x, x]` | ✓ |
| `)` | `[x]` | ✓ |
| `)` | `[]` | ✓ (valid) |

| Input | Stack After | Valid? |
|-------|-------------|--------|
| `)` | (empty!) | ✗ (pop on empty) |
| `(()` | `[x]` | ✗ (stack not empty at end) |

## 11.2 Multiple Bracket Types

### 4 Bracket Types:
| Left | Right |
|------|-------|
| `(` | `)` |
| `[` | `]` |
| `{` | `}` |
| (vinculum - not typable) | |

### Algorithm:
- **Left bracket** → push **corresponding right bracket**
- **Right bracket** → pop and **match**

### Code:
```c
char str[MAXSIZE + 1];
scanf("%s", str);

stack_t s; init_stack(&s);
int is_valid = 1;
char ch, *p = str;

while (is_valid && (ch = *p++) != '\0') {
    if (ch == '(') push(&s, ')');
    else if (ch == '[') push(&s, ']');
    else if (ch == '{') push(&s, '}');
    
    else if (ch == ')' || ch == ']' || ch == '}') {
        if (!is_empty(&s)) {
            if (ch != pop(&s))  // Must match!
                is_valid = 0;
        }
        else
            is_valid = 0;  // Right before left
    }
}

if (is_valid && is_empty(&s))
    printf("Well formed\n");
else
    printf("Not well formed\n");
```

### Trace: `([{}])`
| Char | Stack | Match? |
|------|-------|--------|
| `(` | `)` | - |
| `[` | `], )` | - |
| `{` | `}, ], )` | - |
| `}` | pop `}` ✓ | `], )` |
| `]` | pop `]` ✓ | `)` |
| `)` | pop `)` ✓ | `[]` |

### Invalid Cases:
| Input | Why Invalid |
|-------|-------------|
| `([)]` | `)` expects `)`, finds `}` |
| `([]])` | Extra `]` after match |
| `(][)` | `]` before `[` |

## 11.3 Infix to Postfix Conversion

### Notations:
| Notation | Example | Operator Position |
|----------|---------|-------------------|
| **Infix** | `a + b * c` | Between operands |
| **Postfix** | `a b c * +` | After operands |
| **Prefix** | `+ a * b c` | Before operands |

### Why Postfix?
- No parentheses needed
- No precedence rules
- Left-to-right evaluation
- Stack-friendly

### Algorithm (Shunting Yard):
```c
// Input: infix string
// Output: postfix string
// Stack: operators

for each token in infix:
    if operand: output
    else if '(': push '('
    else if ')': pop until '('
    else if operator:
        while stack not empty AND top has >= precedence:
            pop to output
        push current operator
end for
pop remaining operators to output
```

### Precedence:
| Operator | Precedence | Associativity |
|----------|------------|---------------|
| `^` | 3 | Right |
| `* / %` | 2 | Left |
| `+ -` | 1 | Left |

### Example: `a + b * c`
| Token | Stack | Output |
|-------|-------|--------|
| `a` | - | `a` |
| `+` | `+` | `a` |
| `b` | `+` | `a b` |
| `*` | `+ *` | `a b` |
| `c` | `+ *` | `a b c` |
| end | pop `*`, pop `+` | `a b c * +` |

**Result:** `a b c * +`

### Code Skeleton:
```c
int precedence(char op) {
    if (op == '^') return 3;
    if (op == '*' || op == '/' || op == '%') return 2;
    if (op == '+' || op == '-') return 1;
    return 0;
}

void infix_to_postfix(char* infix, char* postfix) {
    stack_t s; init_stack(&s);
    char *p = infix, *out = postfix;
    
    while (*p) {
        if (isalnum(*p)) *out++ = *p;  // operand
        else if (*p == '(') push(&s, '(');
        else if (*p == ')') {
            while (!is_empty(&s) && s->top_ != '(') *out++ = pop(&s);
            pop(&s);  // pop '('
        }
        else {  // operator
            while (!is_empty(&s) && s->top_ != '(' && 
                   precedence(s->top_) >= precedence(*p))
                *out++ = pop(&s);
            push(&s, *p);
        }
        ++p;
    }
    while (!is_empty(&s)) *out++ = pop(&s);
    *out = '\0';
}
```

## 11.4 Postfix Evaluation

### Algorithm:
```
Scan postfix left to right:
  Operand → push
  Operator → pop 2 operands, apply, push result
Result = top of stack
```

### Example: `3 4 + 5 *`
| Token | Stack | Action |
|-------|-------|--------|
| `3` | `3` | push 3 |
| `4` | `3, 4` | push 4 |
| `+` | `7` | pop 4,3 → 3+4=7, push 7 |
| `5` | `7, 5` | push 5 |
| `*` | `35` | pop 5,7 → 7*5=35, push 35 |

**Result:** `35`

### Code:
```c
int eval_postfix(char* postfix) {
    stack_t s; init_stack(&s);
    char *p = postfix;
    
    while (*p) {
        if (isdigit(*p)) {
            push(&s, *p - '0');
        } else {
            int b = pop(&s);
            int a = pop(&s);
            switch (*p) {
                case '+': push(&s, a + b); break;
                case '-': push(&s, a - b); break;
                case '*': push(&s, a * b); break;
                case '/': push(&s, a / b); break;
            }
        }
        ++p;
    }
    return pop(&s);
}
```

## MCQ Practice

**Q1:** For `([{}])`, what is pushed when `[` is seen?
**A:** `]`

**Q2:** Infix `a+b*c` → Postfix?
**A:** `a b c * +`

**Q3:** Postfix `3 4 + 5 *` = ?
**A:** 35

**Q4:** Infix `a+b-c` → Postfix?
**A:** `a b + c -` (left associative)

**Q5:** What does `is_valid && is_empty(s)` check at end?
**A:** All left brackets matched, no extra right brackets

**Q6:** Precedence of `^` vs `*`?
**A:** `^` higher (3 vs 2)

**Q7:** Why push `(` onto stack?
**A:** Marks subexpression start; pop until `)` found
