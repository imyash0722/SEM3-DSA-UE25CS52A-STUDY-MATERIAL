# Unit 1: Linked Lists and Ordered Lists

## 7.1 Self-Referential Structures

### The Problem:
```c
struct Z { int c; struct Z z; };  // ERROR: infinite recursion!
```
- `Z` contains `Z` → infinite size
- Compiler can't compute size

### The Solution: Pointer to Self
```c
struct A { int c; struct A *p; };  // OK!
```
- Pointer size is fixed (8 bytes on 64-bit)
- Compiler can compute total size
- Called **self-referential structure**

### Example:
```c
struct A one;
one.c = 10;
one.p = &one;        // Points to itself
one.p->c == 10;      // 10
one.p->p->c == 10;   // 10 (infinite chain!)
```

## 7.2 Singly Linked List

### Node Structure:
```c
struct node {
    int key_;
    struct node *next_;
};
typedef struct node node_t;
```
- Self-referential via `next_`
- `next_` = NULL means end of list

### Creating Nodes:
```c
node_t *p = (node_t*)malloc(sizeof(node_t));
p->key_ = 20;
p->next_ = NULL;

p->next_ = (node_t*)malloc(sizeof(node_t));
p->next_->key_ = 40;

p->next_->next_ = (node_t*)malloc(sizeof(node_t));
p->next_->next_->key_ = 60;
p->next_->next_->next_ = NULL;
```

**Result:**
```
p → [20|•] → [40|•] → [60|NULL]
```

## 7.3 Traversal

### Display Function:
```c
void disp(node_t* q) {
    while(q != NULL) {
        printf("%d ", q->key_);
        q = q->next_;  // MOST IMPORTANT STATEMENT!
    }
}
```

### Execution Trace (for list 10→20→30→40→50):
| Iteration | q points to | Prints | q = q->next_ |
|-----------|-------------|--------|--------------|
| 1 | 10 | 10 | moves to 20 |
| 2 | 20 | 20 | moves to 30 |
| 3 | 30 | 30 | moves to 40 |
| 4 | 40 | 40 | moves to 50 |
| 5 | 50 | 50 | moves to NULL |
| 6 | NULL | loop ends | |

**Output:** `10 20 30 40 50`

## 7.4 Freeing List (Critical!)

### WRONG:
```c
free(p);  // Only frees first node! Rest = GARBAGE (memory leak)
```

### CORRECT:
```c
void freelist(node_t* q) {
    node_t* r;
    while(q != NULL) {
        r = q->next_;  // Save next BEFORE freeing
        free(q);
        q = r;
    }
}
```

### Execution Trace:
| Step | q points to | r = q->next_ | free(q) | q = r |
|------|-------------|--------------|---------|-------|
| 1 | 10 | 20 | free(10) | 20 |
| 2 | 20 | 30 | free(20) | 30 |
| 3 | 30 | 40 | free(30) | 40 |
| 4 | 40 | 50 | free(40) | 50 |
| 5 | 50 | NULL | free(50) | NULL |
| 6 | NULL | loop ends | | |

**Rule:** Always save `next` BEFORE `free`ing current node!

## 7.4 Ordered List (Sorted Insertion)

### List Structure:
```c
struct node { int key_; struct node *next_; };
struct mylist { node_t *head; };
typedef struct mylist mylist_t;
```

### Interface:
```c
void init_list(mylist_t*);    // head = NULL
void insert_list(mylist_t*, int key);
void disp_list(mylist_t*);
void free_list(mylist_t*);
```

### Insertion Algorithm (4 Cases):

#### Case 1: Empty List
```c
if(ptr_list->head == NULL) {
    ptr_list->head = temp;
    temp->next_ = NULL;
}
```

#### Cases 2-4: Non-Empty (Find Position)
```c
node_t* prev = NULL;
node_t* pres = ptr_list->head;
while(pres != NULL && pres->key_ < temp->key_) {
    prev = pres;
    pres = pres->next_;
}
```

#### Insert Based on Position:
```c
if(prev == NULL) {           // Insert at BEGINNING
    temp->next_ = pres;
    ptr_list->head = temp;
}
else {                       // MIDDLE or END (same code!)
    temp->next_ = pres;
    prev->next_ = temp;
}
```

### Trace: Insert 10, 20, 50, 30, 40

**Insert 20 (empty):**
```
Head → [20|NULL]
```

**Insert 10 (beginning):**
```
prev=NULL, pres=20 → prev==NULL
temp->next=pres; head=temp
Head → [10|•] → [20|NULL]
```

**Insert 50 (end):**
```
prev=20, pres=NULL (loop exits)
temp->next=NULL; prev->next=temp
Head → [10|•] → [20|•] → [50|NULL]
```

**Insert 30 (middle):**
```
Loop: 10<30 (prev=10, pres=20)
      20<30 (prev=20, pres=50)
      50<30 FALSE → exit
prev=20, pres=50
temp->next=50; prev->next=30
Head → [10|•] → [20|•] → [30|•] → [50|NULL]
```

**Insert 40 (middle):**
```
Loop: 10<40, 20<40, 30<40, 50<40 FALSE
prev=30, pres=50
temp->next=50; prev->next=40
Head → [10|•] → [20|•] → [30|•] → [40|•] → [50|NULL]
```

## 7.5 Complete Implementation

### Header (mylist.h):
```c
struct node { int key_; struct node *next_; };
typedef struct node node_t;

struct mylist { node_t *head; };
typedef struct mylist mylist_t;

void init_list(mylist_t*);
void insert_list(mylist_t*, int);
void disp_list(mylist_t*);
void free_list(mylist_t*);
```

### Implementation (mylist.c):
```c
void init_list(mylist_t* l) { l->head = NULL; }

void insert_list(mylist_t* l, int key) {
    node_t* temp = malloc(sizeof(node_t));
    temp->key_ = key; temp->next_ = NULL;
    
    if(l->head == NULL) {
        l->head = temp;
    } else {
        node_t *prev = NULL, *pres = l->head;
        while(pres && pres->key_ < key) {
            prev = pres; pres = pres->next_;
        }
        if(prev == NULL) {  // Beginning
            temp->next_ = pres;
            l->head = temp;
        } else {  // Middle or End
            temp->next_ = pres;
            prev->next_ = temp;
        }
    }
}

void disp_(node_t* q) {
    while(q) { printf("%d ", q->key_); q = q->next_; }
}
void disp_list(mylist_t* l) { disp_(l->head); printf("\n"); }

void free_list_(node_t* q) {
    node_t* r;
    while(q) { r = q->next_; free(q); q = r; }
}
void free_list(mylist_t* l) { free_list_(l->head); }
```

### Client (client.c):
```c
#include "mylist.h"
int main() {
    mylist_t l; init_list(&l);
    int a[] = {20, 10, 50, 30, 40};
    for(int i=0; i<5; ++i) insert_list(&l, a[i]);
    disp_list(&l);  // 10 20 30 40 50
    free_list(&l);
}
```

|-----------|------|-------|

## MCQ Practice

**Q1:** Why can't we use `q++` to traverse linked list?
**A:** Nodes not contiguous in memory (unlike arrays)

**Q2:** What happens if you `free(p)` on list head without traversing?
**A:** Memory leak — rest of list becomes garbage

**Q3:** In ordered insert, when is `prev == NULL`?
**A:** Insert at beginning (new node < head)

**Q4:** Why save `next` before `free`?
**A:** After `free`, memory invalid; can't access `q->next_`

**Q5:** In ordered insert, middle and end cases use same code?
**A:** Yes — both do `temp->next = pres; prev->next = temp;`

**Q6:** What is `q = q->next_` called?
**A:** "Most important statement in data structures"
