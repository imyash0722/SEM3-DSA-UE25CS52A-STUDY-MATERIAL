# Unit 1: Arrays

## 2.1 Array Characteristics

| Property | Description |
|----------|-------------|
| **Homogeneous** | All elements same type |
| **Fixed size** | Specified at compile time (or C99 VLA at runtime) |
| **No grow/shrink** | Size immutable after creation |
| **Zero-based indexing** | Indices: 0 to n-1 |
| **Random access** | O(1) access time, independent of position |
| **Compile-time** | Knows size, type |
| **Runtime** | Degenerates to pointer (size lost) |
| **No bounds checking** | Undefined behavior on out-of-bounds |

### Philosophy:
> "The programmer gets what he deserves!" - No runtime checking; checking would cost memory and time.

---

## 2.2 Array Declaration and Initialization

### Full Initialization:
```c
int a[5] = {11, 22, 33, 44, 55};  // size 5, all initialized
int a[] = {10, 20, 30, 40, 50};   // size inferred = 5
```

### Partial Initialization:
```c
int c[5] = {11, 22};   // Remaining 3 elements = 0
int b[5];              // Uninitialized (garbage) if local/block scope
```

### Access:
```c
a[2]  // Valid: r-value (read) or l-value (write)
a[5]  // Undefined behavior! No runtime check.
```

## 2.3 Array Traversal Methods

### Method A: Indexing
```c
int a[] = {10, 20, 30, 40, 50}; int n = 5;
for(int i = 0; i < n; ++i)
    printf("%d ", a[i]);
```

### Method B: Pointer Variable (Version 1)
```c
int a[] = {10, 20, 30, 40, 50}; int n = 5;
int *p = a;  // p points to a[0]
for(int i = 0; i < n; ++i)
    printf("%d ", p[i]);  // p[i] same as a[i]
```

### Method C: Pointer Arithmetic (Version 2)
```c
int a[] = {10, 20, 30, 40, 50}; int n = 5;
int *p = a;
for(int i = 0; i < n; ++i)
    printf("%d ", *(p + i));  // or *(a + i)
```

**Valid Pointer Arithmetic:**
| Operation | Valid? |
|-----------|--------|
| `ptr + int` | ✓ |
| `ptr - int` | ✓ |
| `ptr1 - ptr2` (same array) | ✓ |
| `ptr + ptr` | ✗ |
| `ptr * int` | ✗ |

**Rule:** Adding integer advances by that many elements (scaled by sizeof(element))

## 2.4 Pointer Increment (Version 3)

### Key Distinction:
| Expression | What Happens |
|------------|--------------|
| `(*p)++` | Increment **value** at `p` (old value returned) |
| `*p++` | Increment **pointer** `p` (old value returned) |

```c
int a[] = {10, 20, 30, 40, 50};
int *p = a;
for(int i = 0; i < 5; ++i)
    printf("%d ", *p++);  // Print a[i], then advance p
```

**Why `*p++` works:** Post-increment on pointer, then dereference old address.

## 2.5 Array vs Pointer Variable

### Critical Difference:
| Operation | Pointer `p` | Array `a` |
|-----------|-------------|-----------|
| `p = a` | ✓ | N/A |
| `p++` | ✓ | ✗ (constant pointer) |
| `a++` | N/A | ✗ Error! |

```c
int a[] = {10, 20, 30};
int *p = a;
// a++  // ERROR: array is constant pointer
p++;   // OK
```

## 2.6 Passing Arrays to Functions

### Core Rule:
**Array parameter is a POINTER, not an array.**

```c
void read_array(int x[], int n);   // x is int*
void disp_array(int *x, int n);    // same!
```

**Why:** At runtime, array degenerates to pointer. Size information lost!

### Three Ways to Handle Array Size:
| Method | Description |
|--------|-------------|
| **a) Array + size** | Pass `int* x, int n` |
| **b) Begin + end pointers** | Pass `int* start, int* end` |
| **c) Sentinel** | Special value marks end (like `\0` in strings) |

### Example: Array + Size
```c
void read_array(int x[], int n) {
    for(int i = 0; i < n; ++i)
        scanf("%d", x++);  // x = &x[0]; x++ advances
}

void disp_array(int *x, int n) {
    for(int i = 0; i < n; ++i)
        printf("%d ", *x++);
    printf("\n");
}
```

**Note:** `int x[]` and `int *x` are identical in parameter lists.

## 2.7 Array and Pointer Equivalences

### In Expressions:
| Array Expression | Pointer Equivalent |
|-------------------|---------------------|
| `a[i]` | `*(a + i)` |
| `a` (value) | `&a[0]` (address of first) |
| `&a[i]` | `a + i` |

### In Parameter Lists:
```c
void f(int x[])    // Same as
void f(int *x)     // Identical!
```

## 2.8 Multi-dimensional Arrays (Preview)

```c
int a[2][3] = {{1,2,3}, {4,5,6}};
// a is array of 2 arrays of 3 ints
// a[0] is int[3], decays to int* (first row)
// a[i][j] ≡ *(*(a + i) + j)
```

## Summary Table

| Concept | Key Point |
|---------|-----------|
| **Size at runtime** | Lost; array → pointer |
| **Bounds checking** | None (undefined behavior) |
| **Array assignment** | Not allowed (`a = b` invalid) |
| **Parameter type** | Always pointer (`int*` or `int[]`) |
| **Size parameter** | Must pass separately (or use sentinel) |
| **Pointer arithmetic** | `p+i` advances by `i * sizeof(*p)` |
| `(*p)++` vs `*p++` | Value increment vs pointer increment |
| `a` vs `p` | `a` is constant; `p` is modifiable |

## MCQ Practice

**Q1:** What is the size of `int a[] = {1,2,3};`?
**A:** 3 elements (12 bytes on 32-bit, 24 bytes on 64-bit)

**Q2:** What does `void f(int a[10])` mean?
**A:** Parameter is `int*`; 10 is ignored (documentation only)

**Q3:** What is `a[2]` equivalent to?
**A:** `*(a + 2)`

**Q4:** Can you assign `int a[5]; int b[5]; a = b;`?
**A:** No! Arrays not assignment compatible.

**Q5:** What happens on `a[5]` for `int a[5]`?
**A:** Undefined behavior (no bounds check)

**Q6:** In `scanf("%d", x++)` inside `read_array(int x[], int n)`, what does `x++` do?
**A:** Advances pointer to next element for next iteration
