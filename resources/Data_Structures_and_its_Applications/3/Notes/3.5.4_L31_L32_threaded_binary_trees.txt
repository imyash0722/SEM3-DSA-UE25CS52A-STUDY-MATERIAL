Threaded binary tree:
In a tree of n nodes, there are only n-1 edges or branches. In a node based implementation, each node 
has 2 pointers. We require only n-1 pointers to point to nodes – these are called structural pointers. So, 
as many as n + 1 pointers will be grounded.
Based on a particular selected order of traversal (say inorder), can we, instead of grounding the left 
pointer, make it point to the predecessor? Similarly, instead of grounding the right pointer, can we make 
it point to the successor? Such a pointer is called a thresad.
How do we make out whether the pointer is a structural pointer or a thread?
To facilitate this, we may require two bit fields. 
Check the structure of the node in the header file : tree.h in the folder threaded.
Lthread is 1 if left is thread and a structural pointer.  Similarly, rthread is 1 if right is a thread and not a 
structural pointer. Otherwise, they will be 0.

There is a helper function to find the leftmost node in the tree.
If the tree is empty, there is no leftmost node. 
Otherwise keep traversing left. Remember no pointers are grounded. So, we will come to know 
that the left subtree is empty if the left is a thread.
static node_t *leftmost(node_t *temp)
{
    if (temp == NULL)
        return NULL;
    while (temp->lthread_ == 0)
        temp = temp->left_;
    return temp;
}
This function inorder finds the leftmost node without a left subtree.
It will display the key and then follow the right if is is a thread.
Otherwise it is a structural pointer. Take one step right and then again find the leftmost node.
