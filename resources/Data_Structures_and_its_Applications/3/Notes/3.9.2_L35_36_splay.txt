Splay Trees
A few points:
A Splay Tree is a self-adjusting Binary Search Tree (BST).
Whenever a node is accessed, move that node to the root.
This operation is called splaying.
There is no concept of balance factor.
Features:

No Extra Metadata: They require no balance accounting data (like color bits in red-
black trees or height numbers in AVL trees), saving memory. 

Locality of Reference: If we access a piece of data once, it moves to the top, making 
subsequent lookups of the same data instantaneous. 

Efficiency: While a single worst-case operation can take time proportional to the number 
of elements, a sequence of m operations is guaranteed to run in time proportional to m * 
log(n, 2).

Dynamic Adaptation: The tree structure continuously morphs to fit the actual access 
pattern of the workload rather than enforcing a rigid shape. 
Uses:

Caches and Memory Allocation: Great for systems where a small subset of data is 
requested repeatedly.

Network Routers: Used to quickly look up frequently matched IP addresses.

Data Compression: Ideal for algorithms that exploit recurring patterns in data streams.
The first diagram in the next page illustrate the three basic operations : Zig-Zig, Zig-zag and Zig. 
We shall discuss them in detail.
