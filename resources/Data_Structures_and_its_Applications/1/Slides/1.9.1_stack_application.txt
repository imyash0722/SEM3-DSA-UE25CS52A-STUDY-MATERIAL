Stack : Well formed parentheses
•
Why Counting Parentheses Is Not Enough
•
Examples: (3 + 4) and ((5 + 6) * (7 + 8)) are well formed.
•
Ignoring other characters gives () and (()()).
•
Equal numbers of '(' and ')' are necessary, but not sufficient.
•
Example: )( is invalid because a right parenthesis occurs before a left one.
•
Example: ())(()) is also invalid

Stack : Applications
Algorithm: Well-Formed Parentheses
1. Initialize the stack.
2. Read the expression as a string and scan character by character.
3. If the character is '(', push a placeholder.
4. If the character is ')', pop; if the stack is empty, the expression is invalid.
5. After processing the expression, the stack must be empty.

Stack Application
Algorithm: Well-Formed Parentheses : C Code
int is_valid = 1;
char ch; char *s = str;
while (is_valid && (ch = *s++) != '\0') {
    if (ch == '(')
        push(&mystack, 'x');
    else if (ch == ')') {
        if (!is_empty(&mystack))
            pop(&mystack);
        else
            is_valid = 0;
    }
}
if (is_valid && is_empty(&mystack))
    printf("Well formed expression");
else
    printf("not well formed expression");

Stack Application
Stack : Applications
Algorithm: Well-Formed Brackets: (), [], {}
•
With multiple bracket types, a generic placeholder is not enough.
•
For '(' push ')'; for '[' push ']'; for '{' push '}'.
•
When a closing bracket is encountered, the stack must not be empty.
•
The closing bracket must match the character at the top of the stack.
•
Well formed: (){}[], ([]{}) and ([{}]).
•
Not well formed: ([)], ([]]) and (][).
