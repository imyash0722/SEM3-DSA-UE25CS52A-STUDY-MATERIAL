Link List
A list is either empty or has a node followed by a list
The nodes are accessed starting from the head of the list
The access is sequential.
In the worst case, we may have to traverse all the nodes before reaching the last node. This may 
require n operations if there are n nodes.
An ordered list is a list where the nodes are arranged in the order of keys.
Nodes should be inserted based on the comparison of the keys.
Nodes can be inserted in an empty list or in the beginning or the middle or the end.

prev tags behind the pres
•
temp is to be inserted between the nodes to which prev and pres point to.
•
What if prev is NULL => insert in the beginning
