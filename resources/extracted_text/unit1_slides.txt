Functions and Pointers
Revision: Functions
•
Associates a sequence of values called arguments with a value the result
•
Arguments are copied to the corresponding parameters on a function call
•
'C' supports parameter passing by value
•
To change an argument through a parameter, a pointer to the argument need to be passed
•
When a function is called, an activation record or stack frame is created and all parameters, local 
variables, temporary variables, return address are stored on the stack
•
When the function returns, the activation record is removed
•
On a function call, the controlled is transferred to the beginning of the function
•
On return, the instruction following the function call gets executed

Functions and Pointers
Revision : Pointers
•
Has three points to note
•
Aliasing : two pointers point to the same location
•
changing the referent through one also affects referencing through the other
•
Dangling pointer : no location; but have access to it
•
Dangling pointers are not dangerous
•
dereferencing a dangling pointer is an undefined behaviour
•
program crashes if you are lucky!
•
Garbage : location; but no access to it
•
location is lost until the program terminates
•
so this is called memory leak
•
'C' does not support garbage collection

===== Page 36 =====

Arrays
Revision Array
•
Array at compile time is an array. It knows everything about itself.
•
Array at runtime degenerates to a pointer.
•
At runtime, the size of the array is not stored.
•
Index out of bounds - accessing elements beyond the size of the array cannot be checked.
•
Checking would require the size of the array at runtime - extra memory
•
Checking would incur some runtime cost.
•
This if done would be penalizing the right programmer
•
So, 'C' follows this philosophy. The programmer gets what he deserves!
•
C array at runtime is a constant pointer
•
So, arrays cannot be assigned one to another. Arrays are not assignment compatible.

Revision: Array
•
Every element of an array itself can be an array
•
This is called multidimensional array
•
Stored in a row major fashion
•
Size of each dimension but for the first required to access an element of the multidimensional array
•
If a 2 D array is passed as an argument to a function, the corresponding parameter is a pointer to an 
array
•
void foo(int a[][10]);  // only 2 D array having 10 columns can be passed as argument
•
void bar(int n, int a[][n]);  // Any 2 D array can be passed as argument as long as the first argument 
indicates the number of columns

int is_valid = 1;
char ch; char *s = str;
while (is_valid && (ch = *s++) != '\0') {
    if (ch == '(')
        push(&mystack, 'x');
    else if (ch == ')') {
        if (!is_empty(&mystack))
            pop(&mystack);
        else
            is_valid = 0;
    }
}

    printf("Well formed expression");

At the end:
result = pop()
