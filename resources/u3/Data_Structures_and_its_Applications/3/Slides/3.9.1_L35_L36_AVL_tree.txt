AVL tree
AVL tree: height balanced binary search tree
•
Searching in a binary search tree may require n comparisons
•
The tree could become skewed – degenerate to a list
•
AVL tree gives a solution to this problem
•
Each node has a balance factor
•
Height(left subtree) – Height(right subtree)
•
Difference is maintained within 1 (-1, 0, 1)
•
Rotate the tree to keep the balance

AVL tree
AVL tree: LR Rotation
Insert: 30, 10, 20
The BST becomes:
        30
       /
      10
        \
         20
The path is:
30 → 10 → 20
The first move is left, but the second is right. Therefore:
Left → Right
This is an LR case. (requires double rotation)
