In a binary tree of n nodes, there are 2n pointers 
•
A tree has n-1 edges.
•
n + 1 pointers are grounded
•
Make the right pointers which are normally grounded to 
point the successor in some traversal
•
Make the left pointers which are normally grounded 
     to point the predecessor in some traversal 
•
Avoid recursive calls while traversing – so efficient in 
time
•
Requires extra space to indicate whether a pointer is a 
structural pointer or a thread
•
Inorder traversal selected in our discussion

Helper function:
// returns the node with no left subtree
static node_t *leftmost(node_t *temp)
{
    if (temp == NULL)
        return NULL;
 
    while (temp->lthread_ == 0)
        temp = temp->left_;
 
    return temp;
}
static void inorder(node_t *root)
{
   // start from the leftmost node in the tree
    node_t *temp = leftmost(root);
 
    while (temp != NULL)
    {
        printf("%d ", temp->key_);
       // find the inorder successor
      // follow the right thread if the pointer is a thread
        if (temp->rthread_ == 1)
            temp = temp->right_;           
        else
       // otherwise find the leftmost of its right subtree
            temp = leftmost(temp->right_);  
    }
}
