2. Array implementation of binary tree based on relating the parent and the two children.
This implementation will only store the components. It does not store indices or pointers to the 
left subtree and the right subtree.
We may or may not use the 0th location of the array. Depending on this, the mapping of the left 
subtree and the right subtree will vary.
0 index based mapping :
Parent : i ,  left child : 2i + 1; right child : 2i + 2 
1 index based mapping :
Parent : i ,  left child : 2i ; right child : 2i + 1
This arrangement is good only for complete binary trees where all nodes at higher levels are full 
and the lower level has all left nodes filled up.
Otherwise, there will be lots of slots in the array will not be filled up.

Whenever we get a new key, we must find a slot in the array to fill up. In our example, we have 
assumed that the next slot is available. But on deletion, slots may be available at different 
locations. To make this robust, we must implement a simple memory manager which keeps a list 
of free slots and gives a free slot when required and adds the slot to the list slot on deletion. 
To make our example simple, we have not implemented the memory manager and also we have 
not implemented the deletion of a key from the tree.

The tree has the root which shall be the index of the root element in the array. Initially, it will be -1 to

The count_ indicates the number of elements filled up. It is also used to find the next slot where the 
insertion can be done. In a robust implementation, the location should come from the free list.

The recursive function checks if the tree is empty. If not, calls the same function recursively on its left

static void disp_recursive(node_t elem[], int temp)

Insert:
The insert function checks whether the array is full. If we have a memory manager, then the list of free 
slots should indicate whether the tree is full.
The count will indicate the slot where the key can be inserted. Then the count is incremented to indicate 
the number of elements after insertion. The left and the right of the new node are always grounded.
Then, insert calls the recursive routine to insert this new node into the tree. This function passes the 
array of nodes, the root and the index where the new node has been inserted.
void insert(tree_t *ptr_tree, int key)
{
if(ptr_tree->count_ == MAXSIZE)
{
printf("tree full\n");
exit(1);
}
int temp = ptr_tree->count_++;
ptr_tree->elem_[temp].key_ = key;
ptr_tree->elem_[temp].left_ = ptr_tree->elem_[temp].right_ = -1;
ptr_tree->root_ = insert_recursive(ptr_tree->elem_, ptr_tree->root_, temp);
}

If the tree is empty, the index of the new node is the root of the tree.
Otherwise, based on the key, insert in the left subtree or the right subtree.
static int insert_recursive(node_t elem[], int root, int temp)
{
if(root == -1)
{
root = temp;
}
else if(elem[root].key_ > elem[temp].key_)
{
elem[root].left_ = insert_recursive(elem, elem[root].left_, temp);
}
else 
{
elem[root].right_ = insert_recursive(elem, elem[root].right_, temp);
}
return root;
}

int number_of_nodes_recursive(node_t elem[], int temp)
{
if(temp == -1)
{
return 0;
}
else 
{
return 1 + number_of_nodes_recursive(elem, elem[temp].left_) 
+ number_of_nodes_recursive(elem, elem[temp].right_);
}
}

To find the number of leaves,  this function calls the corresponding recursive function with the array

This recursive function returns 0 if the tree is empty, returns 1 if the root is a leaf else 
Returns the sum of the number of leaves in the left subtree and the number of leaves in the right 
subtree.
int number_of_leaves_recursive(node_t elem[], int temp)
{
if(temp == -1)
{
return 0;
}
else if(elem[temp].left_ == -1 && elem[temp].right_ == -1)
{
return 1;
}
else
{
return number_of_leaves_recursive(elem, elem[temp].left_) 
+ number_of_leaves_recursive(elem, elem[temp].right_);
}
}

int are_same(tree_t* ptr_tree1, tree_t* ptr_tree2)
{
return are_same_recursive(ptr_tree1->elem_, ptr_tree1->root_, 
ptr_tree2->elem_, ptr_tree2->root_);
}
This recursive function compares the roots. If both the trees are empty, then the trees are same.
If one of the trees is empty, then the trees are different. Otherwise compare the keys and compare the 
left subtrees and right subtrees recursively.
int are_same_recursive(node_t elem1[], int root1, node_t elem2[], int root2)
{
if(root1 == -1 && root2 == -1)
return 1;
else if(root1 == -1 || root2 == -1)
return 0;
else 
return elem1[root1].key_ == elem2[root2].key_ &&
are_same_recursive(elem1, elem1[root1].left_, 
elem2, elem2[root2].left_)  &&
are_same_recursive(elem1, elem1[root1].right_, 
elem2, elem2[root2].right_);
}
