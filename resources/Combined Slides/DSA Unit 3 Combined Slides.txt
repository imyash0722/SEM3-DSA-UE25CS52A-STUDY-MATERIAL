// on the node; recursive; observe the assignment to the root
static node_t* insert_recursive(node_t* root, node_t* temp)
{
if(root == NULL)
{
root = temp;
}
else if(root->key_ > temp->key_)
{
root->left_ = insert_recursive(root->left_, temp);
}
else 
{
root->right_ = insert_recursive(root->right_, temp);
}
return root;
}

static void heapify(int a[], int n, int pos)
{
int i = pos;
int j = 2 * i;
int val = a[i];
int is_heap = 0;
 
while(j <= n && ! is_heap){
if(j + 1 <= n && a[j+1] > a[j])
++j;
if(a[j] > val) {
a[i] = a[j];
i = j;
j = 2 * i;
}
else {
is_heap = 1;
}
 }
a[i] = val;
}


No Extra Metadata: They require no balance accounting data (like color



actual access pattern of the workload rather than enforcing a rigid shape.

Graph
Terminology
   
© Confidential Information of PES University. All Rights Reserved - 2026 
2 / 9
B.TECH » DEPARTMENT OF COMPUTER SCIENCE & ENGINEERING (AI & ML) » DATA STRUCTURES AND ITS APPLICATIONS » UE25CS252A » UNIT 1 » ARRAYS » CLASS 3/12
Vertex (node): An object represented in the graph, such as A.
Edge: A connection between two vertices, such as AB.
Adjacent vertices: Vertices connected directly by an edge; A and B are adjacent.
Incident edge: An edge is incident on each endpoint; AB is incident on A and B.
Degree: The number of edges incident on a vertex in an undirected graph.
In-degree: The number of directed edges entering a vertex.
Out-degree: The number of directed edges leaving a vertex.
Path: A sequence of vertices joined by edges, such as A–B–D–F–H.
Path length: The number of edges in a path; A–B–D–F–H has length 4.

Cycle: A path returning to its starting vertex without repeating intermediate 
vertices, such as A–B–C–A.
Connected graph: An undirected graph where every vertex is reachable from 
every other vertex.
Connected component: A maximal connected part of a graph.
Simple graph: A graph without self-loops or multiple edges between the same 
pair of vertices.
Self-loop: An edge connecting a vertex to itself.
Complete graph: A simple undirected graph where every pair of distinct vertices 
is connected.
Subgraph: A graph formed from a subset of another graph's vertices and edges.
Cyclic / acyclic graph: A graph that contains / does not contain a cycle.

Graph
Euler graph and Hamilton graph
   
© Confidential Information of PES University. All Rights Reserved - 2026 
2 / 9
B.TECH » DEPARTMENT OF COMPUTER SCIENCE & ENGINEERING (AI & ML) » DATA STRUCTURES AND ITS APPLICATIONS » UE25CS252A » UNIT 1 » ARRAYS » CLASS 3/12
A graph is said to be Eulerian if it supports the traversal of all edges once and only 
once and come back to the starting point. The necessary and sufficient condition 
is that the degree of each node should be even.
A graph is said to be Hamiltonian if it supports the traversal all vertices once and 
only once and come back the starting point. We  do not have an efficient solution 
for this.
