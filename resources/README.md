## Detailed Structure & Contents

### 1. `DSA Course Materials/`
- **Master Document**: [`DSA Course Materials & Announcements Index.docx`](file:///mnt/shared/sem3/DSA/resources/DSA%20Course%20Materials/DSA%20Course%20Materials%20%26%20Announcements%20Index.docx) (Course coordinator: Prof. Ankita Singhai, syllabus, grading weightage, deadlines, exam pattern, mini-project tracks).
- **Experiential Learning**: Tasks 1–4, benchmark modules, and memory manager specs.
- **Laboratory Experiments (Labs 1–11)**:
  - `LAB1-Array of Events`: Dynamic arrays, event scheduling (`Lab1_Array_of_Events.pdf`)
  - `LAB2-Ordered List & Rectangles`: Ordered list implementation (`list.c`, `list.h`)
  - `LAB3-Polynomial ADT`: Polynomial operations and ADT specs
  - `LAB4-Infix to Postfix Conversion`: Stack-based conversion (`stack.c`, `stack.h`)
  - `LAB5-Josephus Problem`: Circular list elimination simulation
  - `LAB6-Postfix Expression Evaluation`: Operator evaluation and expression trees
  - `LAB7-Priority Queue & Deque`: Double-ended queues and priority queue arrays
  - `LAB8-Job Scheduler Implementation`: Multi-file scheduler (`job.c`, `job.h`, `client.c`, `makefile`)
  - `LAB9-BST & Level Order Traversal`: Binary search trees & queue BFS (`tree.c`, `tree.h`)
  - `LAB10-Graph Property Checking`: Graph connectivity & adjacency algorithms
  - `LAB11-Graph Adjacency List & Connected Components`: Connected components, DFS/BFS

### 2. `Data_Structures_and_its_Applications/`
- **Unit 1**: Functions & pointers, 1D/2D arrays, structs, dynamic memory (`malloc`/`free`), Singly Linked List, Header Node list, Stacks, Infix-Postfix, Polynomial ADT, Skip Lists.
- **Unit 2**: Circular Linked Lists, Doubly Linked Lists, Queue ADT, Circular Queue, Priority Queue (3 implementations), Deque, Round-robin scheduling, BST foundations.
- **Unit 3**: General Trees, Binary Tree array representation, Threaded Binary Trees, Expression Trees, Binary Heaps & Heap Sort, AVL Trees (rotations), Splay Trees, Graph introduction.
- **Unit 4**: Graph representations (Adjacency Matrix & List), BFS & DFS traversals, Connected Components, Shortest Path (Dijkstra), Hash Tables & Collision Resolution, Tries (Prefix Trees), Suffix Trees.
