Unit 2: Queue (Linked List Implementation)¶

14.1 Queue ADT¶

FIFO: First In, First Out - Front: Remove from here (dequeue) - Rear: Add here (enqueue)

Interface:¶

Operation Description
init Create empty queue
deinit Free all nodes
enqueue(x) Add at rear
dequeue() Remove from front
front() / peek() View front
is_empty() Check empty
is_full() Check full (heap limit)
deinit Free all nodes

14.2 Linked List Design¶

Two Design Options:¶

Design Links Enqueue Dequeue
1. Reverse Rear → ... → Front O(1) O(n) traverse from rear
2. Forward Front → ... → Rear O(1) O(1)

Rule: Singly linked list → front must point to first node, each node points to next arrival.

struct node { int key_; struct node* next_; };
typedef struct node node_t;

struct queue {
    node_t* front_;  // First to leave
    node_t* rear_;   // Last to leave
};
typedef struct queue queue_t;

14.2 Operations¶

Init:¶

void init_queue(queue_t* q) { q->front_ = q->rear_ = NULL; }

Enqueue:¶

void enque(queue_t* q, int key) {
    node_t* temp = malloc(sizeof(node_t));
    temp->key_ = key;
    temp->next_ = NULL;

    if (q->rear_ == NULL) {           // Empty queue
        q->front_ = q->rear_ = temp;  // Both front & rear
    } else {
        q->rear_->next_ = temp;       // Link at rear
        q->rear_ = temp;              // Update rear
    }
}

Dequeue:¶

int deque(queue_t* q) {
    if (q->front_ == NULL) return 0;  // Empty

    node_t* temp = q->front_;
    int key = temp->key_;

    q->front_ = temp->next_;          // Move front
    if (q->front_ == NULL)            // Was last node?
        q->rear_ = NULL;              // Rear also NULL

    free(temp);
    return key;
}

Edge Case: Single Node Dequeue¶

Before: front → [5|NULL] ← rear
temp = front
front = front->next (NULL)
front == NULL → rear = NULL
free(temp)

14.3 Helper Functions¶

Create Node:¶

static node_t* create_node(int key) {
    node_t* temp = malloc(sizeof(node_t));
    temp->key_ = key;
    temp->next_ = NULL;
    return temp;
}

Empty/Full:¶

int is_empty(queue_t* q) { return q->front_ == NULL; }

int is_full(queue_t* q) {
    node_t* temp = malloc(sizeof(node_t));
    if (!temp) return 1;
    free(temp);
    return 0;
}

Deinit:¶

void deinit_queue(queue_t* q) {
    while (!is_empty(q)) deque(q);
}

14.4 Design Comparison¶

Design Link Direction Enqueue Dequeue
1. Reverse Rear ← ... ← Front O(1) O(n) (traverse from rear)
2. Forward Front → ... → Rear O(1) O(1)

Rule: In singly linked list, front→rear direction gives O(1) for both.

14.5 Menu-Driven Client¶

int main() {
    queue_t q; init_queue(&q);
    int opt, val;

    printf("1:enque 2:deque 0:quit\n");
    scanf("%d", &opt);

    while (opt) {
        switch (opt) {
            case 1: scanf("%d", &val); enque(&q, val); break;
            case 2: val = deque(&q); if (val) printf("deque %d\n", val); break;
        }
        printf("1:enque 2:deque 0:quit\n");
        scanf("%d", &opt);
    }
}

MCQ Practice¶

Q1: Singly linked queue: which end must front point to? A: First inserted (oldest) element

Q2: Why does Design 1 (reverse links) have O(n) dequeue? A: Must traverse from rear to find predecessor of front

Q3: In singly linked queue, enqueue is O(1) because? A: Rear pointer directly accessible

Q4: Single node dequeue: what happens to rear? A: rear = NULL (queue becomes empty)

Q5: Linked queue is_full() implementation? A: Try malloc; if fails → full

Q5: When both front and rear point to same node? A: Queue has exactly one element
