Unit 1: Stack¶

10.1 Stack ADT¶

Definition:¶

  • LIFO: Last In, First Out
  • Operations only at one end (top)
  • No traversal support

Interface:¶

Operation Description
create / init Create empty stack
destroy / deinit Release resources
push(x) Add element at top
pop() Remove and return top element
peek() View top without removing
is_empty() Check if empty
is_full() Check if full (array impl)

10.2 Applications¶

Application Description
Stack Frame Function calls: params, locals, return address
Undo/Redo Ctrl+Z in editors (last operation undone first)
Parentheses Matching Check well-formed expressions
Infix→Postfix Convert & evaluate expressions
DFS/Backtracking Graph traversal, branch & bound
Railway Shunting Rearrange coaches with siding stack

10.3 Array Implementation¶

Structure:¶

#define MAXSIZE 5

struct stack {
    char key_[MAXSIZE];
    int top_;    // Index of TOP element
};
typedef struct stack stack_t;

Convention:¶

  • top_ = -1 → Empty
  • top_ = index of top element (not next free slot)

Operations:¶

Init:¶

void init_stack(stack_t* s) { s->top_ = -1; }

Push:¶

void push(stack_t* s, char ch) {
    if (is_full(s)) { printf("full\n"); return; }
    s->key_[++s->top_] = ch;  // Increment THEN store
}

Pop:¶

char pop(stack_t* s) {
    if (is_empty(s)) { printf("empty\n"); return 0; }
    return s->key_[s->top_--];  // Return THEN decrement
}

Empty/Full:¶

int is_empty(stack_t* s) { return s->top_ == -1; }
int is_full(stack_t* s) { return s->top_ == MAXSIZE - 1; }

Deinit:¶

void deinit_stack(stack_t* s) { s->top_ = -1; }

10.4 Linked List Implementation¶

Structure:¶

struct node { char key_; struct node* next_; };
typedef struct node node_t;

struct stack {
    node_t* top_;  // Pointer to top node
};
typedef struct stack stack_t;

Operations:¶

Init:¶

void init_stack(stack_t* s) { s->top_ = NULL; }

Push (Insert at Head):¶

void push(stack_t* s, char ch) {
    if (is_full(s)) return;  // See is_full below

    node_t* temp = malloc(sizeof(node_t));
    temp->key_ = ch;
    temp->next_ = s->top_;   // New node points to old top
    s->top_ = temp;          // top now points to new node
}
Order matters! temp->next_ = s->top_ BEFORE s->top_ = temp

Pop:¶

char pop(stack_t* s) {
    if (is_empty(s)) return 0;

    char val = s->top_->key_;   // 1. Save value
    node_t* temp = s->top_;     // 2. Save node to free
    s->top_ = s->top_->next_;   // 3. Move top to next
    free(temp);                 // 4. Free old node
    return val;                 // 5. Return value
}
Order critical! Don't free before saving value/next.

Empty:¶

int is_empty(stack_t* s) { return s->top_ == NULL; }

Full (Heap Check):¶

int is_full(stack_t* s) {
    node_t* temp = malloc(sizeof(node_t));
    if (!temp) return 1;   // Allocation failed
    free(temp);
    return 0;
}
Note: Allocates and frees test node — expensive but only way in C.

Deinit:¶

void deinit_stack(stack_t* s) {
    while (!is_empty(s)) pop(s);  // Pop all nodes
}

10.5 Client Code (Same for Both!)¶

// client.c
#include "stack.h"

int main() {
    stack_t s; init_stack(&s);

    char str[100];
    scanf("%s", str);

    for (int i = 0; str[i]; ++i)
        push(&s, str[i]);

    while (!is_empty(&s))
        printf("%c", pop(&s));
    printf("\n");

    deinit_stack(&s);
}
Input: hello
Output: olleh (reversed!)

10.6 Comparison¶

Aspect Array Linked List
Size Fixed (MAXSIZE) Dynamic (heap)
Push/Pop O(1) O(1)
Memory Contiguous Scattered (heap)
Full check top == MAX-1 malloc test
Empty top == -1 top == NULL
Client recompile If MAXSIZE changes If struct changes

10.6 Stack Frame (Activation Record)¶

main() calls f1() calls f2()

Stack:
+------------------+  ← Top (f2)
| f2: params       |
| f2: locals       |
| f2: temps        |
| return addr      |
+------------------+  ← f1's frame
| f1: params       |
| f1: locals       |
| f1: temps        |
| return addr      |
+------------------+  ← Bottom (main)
| main: params     |
| main: locals     |
| return addr      |
+------------------+

10.7 Expression Evaluation (Preview)¶

Infix → Postfix (Shunting Yard):¶

Infix:    a + b * c
Postfix:  a b c * +

Algorithm (Stack of Operators):¶

  1. Scan infix left→right
  2. Operand → output
  3. Operator → pop higher/equal precedence → push current
  4. ( → push; ) → pop until (
  5. End → pop all remaining

Evaluation (Stack of Operands):¶

Postfix:  3 4 + 5 *
Stack:    push 3, push 4, + → pop 4,3 push 7
          push 5, * → pop 5,7 push 35
Result: 35

Summary Table¶

Aspect Array Stack Linked Stack
Space Fixed O(N) Dynamic O(N)
Push s[++top]=x New node at head
Pop s[top--] Remove head
Empty top==-1 top==NULL
Full top==MAX-1 malloc fails
Deinit top=-1 Pop all nodes

MCQ Practice¶

Q1: Stack principle? A: LIFO (Last In, First Out)

Q2: In array stack with top as index of top element, is_empty? A: top == -1

Q3: Push order in linked stack? A: new->next = top; top = new;

Q4: Pop order in linked stack? A: val = top->data; temp = top; top = top->next; free(temp); return val;

Q5: is_full in linked stack? A: Try malloc; if fails → full (then free test node)

Q6: What does stack frame store? A: Parameters, locals, temps, return address

Q7: is_empty in array stack? A: top == -1

Q8: Convert a + b * c to postfix? A: a b c * +
