Dynamic Allocation
Dynamic Allocation
•
C does not support any operator for memory allocation or deallocation
•
These are realized by using the standard library functions
•
void* malloc(int size);
•
Is a low level function
•
Should indicate how many bytes are required
•
Allocates a block of so many bytes and returns a malleable pointer to it
•
Does book keeping – remembers the size of the block allocated
•
You may cast it to any type you want
•
Returns NULL when it fails

Dynamic Allocation
Dynamic Allocation
•
void free(void *ptr);
•
Frees the block pointed to by ptr
•
Makes the block of memory useful again
•
Observe that we do not specify the size of the block allocated
•
Uses book keeping information created while allocating
•
Calling free on a pointer value not returned by malloc or calling second time are undefined 
behaviour
•
Free(NULL) is a no op.

Dynamic Allocation
Dynamic Allocation
•
Garbage : location with no access
•
Happens only with dynamic allocation
•
Happens when memory is allocated and not freed
•
Happens when the pointer holding the pointer value to the allocated block is changed or dies
•
Garbage becomes memory leak in 'C' as 'C' does not support garbage collector
•
All the garbage is collected when the program terminates
