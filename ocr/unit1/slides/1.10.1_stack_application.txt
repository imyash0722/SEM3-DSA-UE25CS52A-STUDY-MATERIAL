•
Infix notation uses operators between operands: 3 + 4.
•

Stack Application: Expression Conversion and Evaluation
Postfix Evaluation Using a Stack
1. Create a stack of operands.
2. Read the postfix expression from left to right.
3. Operand → push it onto the stack.
4. Operator → pop the required operands, perform the operation,
   and push the result.
5. After the complete expression is processed, the stack contains
   exactly one value: the result.

Stack Application: Expression Conversion and Evaluation
Postfix Evaluation: Algorithm
Read the postfix expression.
Create and initialize a stack of integers.
For each token:
if token is an operand:
push(token)
else if token is an operator:
val2 = pop()
val1 = pop()
result = val1 operator val2
push(result)
At the end:
result = pop()
the stack should now be empty.

Stack Application: Expression Conversion and Evaluation
Postfix Evaluation: order of evaluation
For + and *, operand order does not affect the result.
For – and /, it matters.
If the postfix expression is: 8 3 –
First pop gives val2 = 3; second pop gives val1 = 8.
Compute val1 – val2 = 8 – 3 = 5.
Never compute 3 – 8

•

•

•

Stack Application: Expression Conversion and Evaluation
Conversion from infix to postfix
•
Associate a precedence value with each operator
•
Higher the precedence, higher the value
•
When an operator is encountered, we compare the precedence value of the 
operator in the string with that of the operator in the top of the stack
•
While the first one is higher, push the operator into the stack
•
Otherwise pop the operator from the stack and push the operator
  in the string on to the stack
•
When the input string is completely processed, pop all the operators from the 
stack

A left parenthesis is always pushed onto the operator stack.

It acts as a barrier: operators inside the parentheses are handled before operators
outside.

When a right parenthesis is encountered, pop operators until the matching left
parenthesisis found.

Stack Application: Expression Conversion and Evaluation
Summary
•
Postfix notation removes the need for precedence rules during evaluation.
•
A stack of operands is sufficient for postfix evaluation.
•
Operators pop operands, compute, and push the result.
•
Infix-to-postfix conversion uses a stack of operators.
•
Precedence, associativity, and parentheses determine when operators are popped.
•
The stack can be used through its interface without knowing whether it is 
implemented with an array or a list.
