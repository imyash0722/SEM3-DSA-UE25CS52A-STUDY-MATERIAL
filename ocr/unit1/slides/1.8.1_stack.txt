Stack : Abstract Data Type
stack
•
Is a data structure
•
Has zero or more components
•
Can operate at only one end – normally called the stack top
•
Supports LIFO : Last In First Out
•
What goes in last, comes out first
•
Does not support the concept of traversal

stack

•

•

•
Peek : check the top element without removing it
•
Is_empty : check whether the stack is empty
•
