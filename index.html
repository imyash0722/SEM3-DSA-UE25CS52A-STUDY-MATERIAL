Course Information¶

  • Course: Data Structures and its Applications (UE25CS52A)
  • Instructor: Prof. N S Kumar (nskumar@pes.edu)
  • Textbook: "Data Structures using C/C++" by Tenenbaum et al. (Pearson, 2nd ed., 2015)
  • Reference: "Data Structures and Program Design in C" by Kruse et al. (Pearson, 2nd ed., 2019)

Study Strategy¶

  1. Start with Unit 1 Theory - Master ADT concepts, pointers, memory management
  2. Practice Unit 1 Examples - Write and trace every program
  3. Unit 2 Theory - Compare queue/PQ implementations (table on theory page)
  4. Unit 3 Theory - Focus on BST operations, heapify, AVL rotations, graph representations
  5. Review INDEX - Use checklist before exams

Exam Pattern¶

  • ISA1 (Units 1-2): 40 marks → 20 marks (MCQs: 10×1 + 5×2)
  • ISA2 (Units 3-4): 40 marks → 20 marks (MCQs: 10×1 + 5×2)
  • ESA (All units): 100 marks → 50 marks (20 MCQ + 80 subjective)
