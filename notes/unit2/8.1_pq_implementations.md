## 19.3 Implementation 1: Unordered List

### Structure:
```c
struct node {
    job_t jobx_;
    struct node* next_;
};
typedef struct node node_t;

struct queue {
    node_t* front_;
    node_t* rear_;
};
typedef struct queue queue_t;
```

### Enqueue: O(1) — Add at rear (ignore priority)
```c
void enque(queue_t* q, job_t* job) {
    node_t* temp = malloc(sizeof(node_t));
    temp->jobx_ = *job;
    temp->next_ = NULL;
    
    if (q->rear_ == NULL) {
        q->front_ = q->rear_ = temp;
    } else {
        q->rear_->next_ = temp;
        q->rear_ = temp;
    }
}
```

### Dequeue: O(n) — Scan for max priority
```c
job_t deque(queue_t* q) {
    // Track max with two pointers
    node_t *prev = NULL, *pres = q->front_;
    node_t *max_prev = NULL, *max_pres = q->front_;
    int max_pri = get_priority(&pres->jobx_);
    
    // Scan entire list
    while (pres) {
        int pri = get_priority(&pres->jobx_);
        if (pri > max_pri) {
            max_pri = pri;
            max_prev = prev;
            max_pres = pres;
        }
        prev = pres;
        pres = pres->next_;
    }
    
    // Remove max_pres
    job_t job = max_pres->jobx_;
    if (max_prev == NULL) {           // Case A: First node
        q->front_ = max_pres->next_;
        if (!q->front_) q->rear_ = NULL;
    } else {                          // Case B: Middle/End
        max_prev->next_ = max_pres->next_;
        if (!max_pres->next_) q->rear_ = max_prev;
    }
    free(max_pres);
    return job;
}
```

### Complexity:
| Operation | Time |
|-----------|------|
| Enqueue | O(1) |
| Dequeue | O(n) |
| Space | O(n) |

## 19.4 Implementation 2: Ordered List (by Priority)

### Structure: Same as unordered list

### Enqueue: O(n) — Insert in sorted position (highest at front)
```c
void enque(queue_t* q, job_t* job) {
    node_t* temp = create_node(job);
    
    if (q->front_ == NULL) {          // Empty
        q->front_ = q->rear_ = temp;
        return;
    }
    
    // Find insertion point (descending priority)
    node_t *prev = NULL, *pres = q->front_;
    int pri = get_priority(job);
    
    while (pres && get_priority(&pres->jobx_) >= pri) {
        prev = pres;
        pres = pres->next_;
    }
    
    if (!prev) {                      // Insert at front
        temp->next_ = q->front_;
        q->front_ = temp;
    } else if (!pres) {               // Insert at end
        q->rear_->next_ = temp;
        q->rear_ = temp;
    } else {                          // Middle
        temp->next_ = pres;
        prev->next_ = temp;
    }
}
```

### Dequeue: O(1) — Remove from front
```c
job_t deque(queue_t* q) {
    node_t* temp = q->front_;
    job_t job = temp->jobx_;
    q->front_ = temp->next_;
    if (!q->front_) q->rear_ = NULL;
    free(temp);
    return job;
}
```

### Complexity:
| Operation | Time |
|-----------|------|
| Enqueue | O(n) |
| Dequeue | O(1) |

## 19.5 Implementation 3: Unordered Array

### Structure:
```c
#define MAXSIZE 100

struct pqueue {
    job_t jobs_[MAXSIZE];
    int front_;   // Index of first
    int rear_;    // Index after last
    int size_;
};
```

### Enqueue: O(1)
```c
void enque(pqueue_t* q, job_t* job) {
    if (q->size_ < MAXSIZE) {
        q->jobs_[q->rear_] = *job;
        q->rear_ = (q->rear_ + 1) % MAXSIZE;
        q->size_++;
    }
}
```

## 19.7 Comparison Summary

| Implementation | Enqueue | Dequeue | Space |

## MCQ Practice

**Q1:** Unordered list: Enqueue O(1), Dequeue O(n)?
**A:** Yes — add at rear, scan for max

**Q2:** Ordered list: Enqueue O(n), Dequeue O(1)?
**A:** Yes — insert sorted, remove from front

**Q3:** Which is better for frequent enqueues?
**A:** Unordered list/array

**Q3:** Which is better for frequent dequeues?
**A:** Ordered list/array

**Q4:** Best overall?
**A:** Heap — O(log n) both operations

**Q4:** Equal priority — FIFO tie-break means?
**A:** Earlier inserted removed first
