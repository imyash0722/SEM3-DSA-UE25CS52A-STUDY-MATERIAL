## 18.1 Tree Fundamentals

### Definition:
A **tree** is a non-linear data structure representing hierarchical relationships.

### Recursive Definition:
- Empty, OR
- Root + zero or more subtrees (each a tree)

### Genealogy Terms:
| Term | Meaning |
|------|---------|
| **Root** | Topmost node |
| **Parent** | Node with children |
| **Child** | Node directly below parent |
| **Siblings** | Same parent |
| **Leaf** | No children (external node) |
| **Internal Node** | Has ≥1 child |
| **Edge** | Parent-child connection |
| **Path** | Sequence of nodes connected by edges |
| **Ancestor** | On path from root to node |
| **Descendant** | Below given node |
| **Subtree** | Node + all descendants |

### Botany Terms:
| Term | Meaning |
|------|---------|
| **Root** | Topmost node |
| **Leaf** | No children |
| **Internal Node** | Has children |
| **Edge/Branch** | Parent-child link |
| **Depth** | Edges from root (root=0) |
| **Level** | Nodes at same depth |
| **Height** | Longest path to leaf (leaf=0) |
| **Degree** | Number of children |

### Properties:
| Property | Value |
|----------|-------|
| Acyclic | No cycles |
| Connected | Path between any two nodes |
| n nodes | n-1 edges |
| Add edge | Creates cycle |
| Remove edge | Disconnects (forest) |

## 18.4 General Tree → Binary Tree

**Left-Child Right-Sibling Representation:**
1. Root stays root
2. First (leftmost) child → **Left child**
3. Next sibling → **Right child**

```
General:          Binary (LCRS):
    A                  A
  / | \               /
 B  C  D             B → C → D
|  |                  |
E  F                  E
```

## 18.5 Binary Tree

### Definition:
- Each node has **at most 2 children**
- Distinguished as **Left** and **Right**
- Recursive: Empty OR Root + Left Subtree + Right Subtree

### ADT Operations:
| Operation | Description |
|-----------|-------------|
| `Create()` | Empty tree |
| `Destroy()` | Free all nodes |
| `root()` | Return root |
| `parent(p)` | Parent of p |
| `left(p)` | Left child |
| `right(p)` | Right child |
| `isLeaf(p)` | Test leaf |
| `component(p)` | Data at p |
| `addRoot(x)` | Create root |
| `addLeft(p,x)` | Add left child |
| `addRight(p,x)` | Add right child |
| `remove(p)` | Remove subtree |
| `size()` | Node count |
| `height()` | Tree height |

## 18.6 Binary Search Tree (BST)

### Property:
- `left.key < root.key < right.key` for all nodes
- Insertion always at **leaf**

### Structure:
```c
struct node {
    int key_;
    struct node *left_;
    struct node *right_;
};
typedef struct node node_t;

struct tree {
    node_t *root_;
};
typedef struct tree tree_t;
```

---

## 18.7 BST Operations

### Init/Deinit:
```c
void init(tree_t* t) { t->root_ = NULL; }
void deinit(tree_t* t) {
    deinit_rec(t->root_);
    t->root_ = NULL;
}
static void deinit_rec(node_t* n) {
    if (n) { deinit_rec(n->left_); deinit_rec(n->right_); free(n); }
}
```

### Inorder Traversal (Sorted Output):
```c
void disp(tree_t* t) {
    disp_rec(t->root_); printf("\n");
}
static void disp_rec(node_t* n) {
    if (n) { disp_rec(n->left_); printf("%d ", n->key_); disp_rec(n->right_); }
}
```

### Insert (Returns Updated Root):
```c
void insert(tree_t* t, int key) {
    node_t* temp = malloc(sizeof(node_t));
    temp->key_ = key; temp->left_ = temp->right_ = NULL;
    t->root_ = insert_rec(t->root_, temp);
}

static node_t* insert_rec(node_t* root, node_t* temp) {
    if (!root) return temp;
    if (root->key_ > temp->key_)
        root->left_ = insert_rec(root->left_, temp);
    else
        root->right_ = insert_rec(root->right_, temp);
    return root;
}
```

## 18.8 Tree Queries

### Node Count:
```c
int count_nodes(tree_t* t) { return count_rec(t->root_); }
int count_rec(node_t* n) {
    if (!n) return 0;
    return 1 + count_rec(n->left_) + count_rec(n->right_);
}
```

### Leaf Count:
```c
int count_leaves(tree_t* t) { return leaves_rec(t->root_); }
int leaves_rec(node_t* n) {
    if (!n) return 0;
    if (!n->left_ && !n->right_) return 1;
    return leaves_rec(n->left_) + leaves_rec(n->right_);
}
```

## 18.9 Recursive Pattern

All tree functions follow this pattern:
```c
int func(node_t* n) {
    if (!n) return BASE_CASE;
    return COMBINE(func(n->left_), func(n->right_));
}
```

| Query | Base | Combine |
|-------|------|---------|
| Count nodes | 0 | 1 + L + R |
| Count leaves | 0 | 1 if leaf else L + R |
| Height | -1 | 1 + max(L, R) |
| Search | false | L || R |

## Summary Table

| Concept | Key Point |
|---------|-----------|
| **Tree** | Acyclic, connected, n nodes = n-1 edges |
| **BST** | left < root < right; insert at leaf |
| **Traversal** | Inorder gives sorted order |
| **Recursive** | Tree calls node's recursive functions |
| **Deinit** | Postorder: left, right, root |
| **Insert** | Returns new root of subtree |

## MCQ Practice

**Q1:** BST insertion always happens at?
**A:** Leaf node

**Q2:** Inorder traversal of BST gives?
**A:** Sorted order

**Q3:** Tree with n nodes has how many edges?
**A:** n-1

**Q4:** Height of leaf?
**A:** 0

**Q5:** Deinit order?
**A:** Postorder (left, right, root)

**Q5:** Insert returns?
**A:** Updated root of subtree
